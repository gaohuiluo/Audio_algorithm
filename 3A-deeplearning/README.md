## 写作风格与约束

全系列共同遵守的硬约束（与信号与系统、深度学习基础一脉相承，详见 `_STYLE_GUIDE.md`）：

1. **直觉先行，数学兜底**：先给物理/工程画面，再上唯一核心公式，且逐项翻译成人话。
2. **所有例子锚定音频/语音**：降噪、回声、双讲、混响、声码器。禁用猫狗/房价，注意力也用"语音帧互查"讲，不用 NLP 词。
3. **比喻必须有解释力**：逐频带增益=给每段单独拧音量旋钮、双讲=同时说话时只抠掉对方声音、扩散=把语音泡进噪声再一步步捞回来。
4. **代码把公式变成可运行**：PyTorch 最小可跑实现，张量操作后必打印 shape。不产出独立脚本/PNG/WAV。
5. **讲"为什么需要"，落到工程**：实时因果红线、端侧算力预算、定点化、流式状态缓存、数据合成、指标与听感的背离。

## 贯穿全系列的一条主线

10 篇不是 10 个孤岛，是一条连贯的河。每篇结尾的"埋一个钩子"都直接引出下一篇：

```
第一个真实模型(01 RNNoise)
   → 复数谱端到端(02 DCCRN) → 多分辨率治非平稳噪声(03 FullSubNet)
   → 注意力:每帧互查(04) / Transformer 与局限(05) / Conformer 卷积+注意力(06)
   → 换任务:回声消除(07 AEC)
   → 换范式:声码器/GAN(08) / 扩散模型(09)
   → 怎么证明谁好:评估 + 面试(10)
```

一条更抽象的暗线贯穿始终——**判别式 → 生成式的范式迁移，以及"实时因果性"这条红线如何一路约束每个模型的取舍。** 顺着读，你会发现：任何一个复杂的语音前端模型，都不过是基础系列那些零件（卷积、门控、复数层、注意力、损失）针对具体任务的重新组合。

## 阅读建议

按序号顺读。每篇都建立在前一篇的钩子之上：不懂 RNNoise 为什么"只修幅度是天花板"，就理解不了 DCCRN 为什么要啃复数谱；不懂 RNN 记忆是"一根线"的瓶颈，就看不透注意力为什么让任意两帧直接对话；不懂判别式模型的上限，就不知道生成式在救什么。顺着读，10 篇下来，你手里就有了一张能看懂论文、能落地端侧、能在面试里讲透的 DL 3A 全景地图。
