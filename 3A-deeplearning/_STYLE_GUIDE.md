## 0. 受众与定位

- **受众**：有音频/驱动背景、**已读完信号与系统系列 + 深度学习基础系列**、正从驱动工程师转型语音算法工程师的人。

## 1. 五条硬约束（继承基础系列，一字不改地执行）

### 1.1 直觉先行，数学兜底
每个概念**先给物理/工程画面，再上公式**。公式只保留最核心那一个，出现时**必须逐项翻译成人话**。绝不先甩推导。
> 例：讲 Si-SNR 先带读者"把估计信号投影到目标方向上，算目标分量能量 vs 残差能量的比"，等直觉建立了，投影公式才顺眼。

### 1.2 所有例子锚定音频/语音
一律用降噪、回声消除、语音分离、双讲、混响、声码器举例。张量每一维都要落到真实含义。
**禁用图像分类猫狗、CIFAR、鸢尾花、房价预测、机器翻译英法句子这类通用 ML 教材例子**——注意力也要用"语音帧之间互相查询"来讲，不用 NLP 的词。

### 1.3 比喻必须有解释力，拒绝装饰性换名
只保留能揭示机制的比喻（逐频带增益=给每个频段单独拧一个音量旋钮、注意力=开会时每帧举手提问、双讲=两个人同时说话时你要从麦克风里只抠掉对方的声音、扩散=把语音一点点泡进噪声再一步步捞回来）。坚决去掉只换花哨说法、不推进理解的修辞。

### 1.4 代码把公式变成可运行
用 PyTorch + NumPy 把概念跑出来，能直接运行、注释讲清每步。**本系列一律"记事内可运行片段"，不生成独立脚本、不产出 PNG/WAV 文件。** 张量操作后**务必打印/标注 shape**。模型级实现给"最小可跑版"（能 forward、shape 对得上、核心机制在），不追求复现论文全部工程细节。

### 1.5 讲"为什么需要"，落到工程
重点是"工程中遇到什么问题、为什么要这个模型"。凡有条件补一线视角：实时因果性红线（不能看未来帧）、端侧算力/显存预算、定点化对复数运算的影响、流式推理的状态缓存、数据合成策略、指标与听感的背离。

```
# 第 N 篇｜模型名/主题：一句话副标题

## 这在工程里解决什么问题          ← 表格/bullet，落到降噪/AEC/分离真实任务
## 埋一个钩子                      ← 抛出下一篇要解决的问题，形成连贯脉络

```

排版习惯：
- 核心公式用 `$$...$$`，行内用 `$...$`。
- "关键认知"用 `>` 引用块高亮。
- 工程对照、维度含义、方案选型、指标对比常用**表格**。
- 代码块给完整可运行片段，带中文注释，张量操作后标注 shape。
- **每篇目标 ~500-650 行**（比基础系列更深更长，因为模型级内容更复杂；推导与代码都要给足）。

维度顺序约定（继承基础系列，务必贯彻）：
- 波形：`[B, T]` 或 `[B, C, T]`

## 4. 十篇总脉络与"钩子接续点"（连续性命脉）

开篇 README 承接 deep-learning 基础系列收官钩子。一条主线：
**第一个真实模型(RNNoise) → 复数谱端到端(DCCRN) → 多分辨率(FullSubNet) → 注意力革命(自注意力/Transformer/Conformer) → 换任务(AEC) → 换范式(生成式:声码器/扩散) → 怎么证明谁好(评估+面试)。**

|---|---|---|---|---|
| 00 | `README.md` | DL 3A 全景地图：8 类经典模型是基础系列零件的重新组合 | 承接基础系列收官"具体降噪/分离/AEC 模型实战" | 从最小、最经典、能跑在端侧的 RNNoise 起步 |
