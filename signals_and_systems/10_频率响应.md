# 第 10 篇｜频率响应：滤波器的"性格画像"

> 一句话核心直觉：把系统的冲激响应做一次傅里叶变换，就得到一条曲线，它精确告诉你——**这个系统对每一个频率，到底是放大还是削弱、放大或削弱多少**。这条曲线，就是你在 EQ 插件里拖来拖去的那条线。

---

## 一、先别看公式，我们调一次 EQ

打开任何一个均衡器（EQ）插件，你面前是一条横躺的曲线：横轴是频率，从 20 Hz 到 20 kHz；纵轴是增益，单位 dB。你在 8 kHz 附近往上拖一个包，人声立刻"亮"了；你在 200 Hz 挖一个坑，浑浊的低频立刻干净了。

你有没有想过一个问题：**这条曲线，到底是什么东西的图像？** 它凭什么能代表一个滤波器？

考研时我背过"频率响应是系统函数在虚轴上的取值"，能算题，但心里那个疙瘩一直在：这条曲线和第 5 篇那段"啪……嗡"的冲激响应，是什么关系？

答案干脆得出人意料：**这条曲线，就是冲激响应做傅里叶变换的结果。** 时域里那段回响 $h[n]$，和频域里这条 EQ 曲线 $H(f)$，是**同一个系统的两张照片**——一张拍的是"它在时间上怎么拖尾"，一张拍的是"它对各个频率什么态度"。

---

## 二、频率响应到底是"什么对什么的比值"

要真正懂这条曲线，得先想清楚一件事：**一个 LTI 系统，对一个纯音（单一频率的正弦）会做什么？**

这里有一条 LTI 系统最要命、也最优美的性质：

> **你喂给一个 LTI 系统一个频率为 $f$ 的正弦波，它吐出来的，仍然是一个频率为 $f$ 的正弦波——频率一点不变，只是幅度被缩放了、相位被挪动了。**

频率不变，这是铁律。系统不会无中生有造出新频率（能造新频率的，就不是线性时不变系统了，比如失真、削波）。它能做的，只有两件事：

- 把这个频率的正弦**放大或缩小**（改变幅度）；
- 把它**往前或往后挪一点**（改变相位）。

那么，一个系统的"性格"就完全定下来了：**只要我知道它对每一个频率分别放大/缩小多少、挪动多少，我就掌握了它的全部行为。** 因为任何声音（第 6~9 篇）都能拆成一堆不同频率的正弦，系统对整段声音的处理，无非是对每个频率成分各自缩放、挪动，再叠回去。

把"对频率 $f$ 的缩放倍数和相位挪动"这两个数，随频率画出来，就是**频率响应 $H(f)$**：

- 它的**幅度** $|H(f)|$：频率 $f$ 被放大（$>1$）还是削弱（$<1$）——这就是 EQ 曲线的纵轴。
- 它的**相位** $\angle H(f)$：频率 $f$ 被延迟了多少——决定波形对齐、群延迟。

所谓"性格画像"，说到底一点都不玄：**它就是一张"逐频率增益表"**，横轴频率、纵轴增益，一个频率对一个数。EQ 曲线之所以能代表滤波器，正因为它画的就是这张表。

## 三、为什么"冲激响应的傅里叶变换"正好就是它


## 三、为什么"冲激响应的傅里叶变换"正好就是它

上一节说频率响应是一张"逐频率增益表"。可这张表从哪来？凭什么它等于 $h[n]$ 的傅里叶变换？

这里我们一步一步推。推导只用两样东西：第 5 篇的卷积公式，和第 3 篇的复指数。如果你那两篇看懂了，下面每一步都不该有跳跃。

### 第 1 步：从卷积公式出发

第 5 篇我们得出结论：LTI 系统对任意输入的处理是卷积——

$$y[n] = \sum_{k} x[k]\,h[n-k]$$

人话翻译：输入的每一个采样 $x[k]$ 各自激起一段"缩放 + 平移"的冲激响应副本，全部叠加就是输出。这个公式是铁板钉钉的起点。

### 第 2 步：选一个"特殊"的输入试探系统

卷积公式对任意输入都成立。如果我想搞清楚"系统对频率 $f$ 的态度"，最自然的办法就是：**输入一个频率为 $f$ 的纯音，看输出是什么。**

第 3 篇我们认识过复指数 $e^{j2\pi f n}$——它就是正弦波和余弦波打了个包。用它当输入不是因为现实中有复数声音，而是**它让计算变得极其干净**。算完之后，结果对真实的正弦波同样成立（第 4 步会回到实数）。

所以令 $x[n] = e^{j2\pi f n}$，代进卷积公式。因为卷积中 $x$ 的自变量是 $k$，所以 $x[k] = e^{j2\pi f k}$：

$$y[n] = \sum_{k} e^{j2\pi f k}\,h[n-k]$$

这一步看着已经可以算了，但为了把"跟 $n$ 有关"和"跟 $n$ 无关"的部分拆开，我们做个变量替换：令 $m = n - k$（也就是 $k = n - m$）。当 $k$ 遍历所有值时 $m$ 也遍历所有值——求和的范围不变。代入后：

$$y[n] = \sum_{m} h[m]\,e^{j2\pi f (n-m)}$$

这个替换很关键：它让 $h$ 的自变量变成了 $m$，而复指数的指数里出现了 $(n-m)$——正是我们下一步要拆的"缝"。

### 第 3 步：拆解指数——这是整段推导的关键

$e^{j2\pi f (n-m)}$ 看起来是个整体，但利用指数运算法则 $e^{a-b} = e^a \cdot e^{-b}$，它可以拆开：

$$e^{j2\pi f (n-m)} = e^{j2\pi f n} \cdot e^{-j2\pi f m}$$

代入回去：

$$y[n] = \sum_{m} h[m] \left( e^{j2\pi f n} \cdot e^{-j2\pi f m} \right)$$

现在仔细观察这个求和式。求和是对 $m$ 进行的。这意味着 $n$ 在求和的视角里是**固定不变的**。而 $e^{j2\pi f n}$ 这个因子里只有 $n$ 和 $f$，**不含 $m$**——所以它可以**提出来**：

$$y[n] = \underbrace{\left( \sum_{m} h[m]\,e^{-j2\pi f m} \right)}_{\text{只跟 } f \text{ 有关，跟 } n \text{ 无关}} \cdot e^{j2\pi f n}$$

### 第 4 步：认识括号里那一坨是什么

停下来看这个式子：$\sum_m h[m]\,e^{-j2\pi f m}$。

它里面有什么？$h[m]$——系统的冲激响应；$e^{-j2\pi f m}$——频率为 $f$ 的复指数的共轭；求和把所有 $m$ 加起来。

**这个式子，正是 $h$ 的离散时间傅里叶变换 (DTFT) 的定义。** 第 7 篇我们见过它：

$$H(f) = \sum_{m} h[m]\,e^{-j2\pi f m}$$

所以整个输出可以写成：

$$y[n] = H(f) \cdot e^{j2\pi f n}$$

### 第 5 步：解读结果——这就是全部的故事

这个等式看着简单，信息量极大。让我慢慢翻译：

- 输入是 $e^{j2\pi f n}$——一个频率 $f$ 的纯音；
- 输出是 $H(f) \cdot e^{j2\pi f n}$——**完全一样的纯音**，前面多了一个系数 $H(f)$；
- $H(f)$ 是个复数。复数乘法只做两件事：**模决定缩放，辐角决定旋转（相位偏移）**。

所以 $H(f)$ 的模 $|H(f)|$ 就是"频率 $f$ 被放大多少倍"，$H(f)$ 的辐角 $\angle H(f)$ 就是"频率 $f$ 被延迟了多少"。

更惊人的是：$H(f)$ 的表达式里只含有 $f$（和系统固有的 $h$），不含 $n$。这意味着对于同一个频率 $f$，**无论你在哪个时刻看，增益和延迟都是一个常数**。系统对频率 $f$ 的态度是稳定的——这正是"时不变"的含义。

### 第 6 步（补充）：那真实的正弦波呢？

你可能会问：上面用的是复指数 $e^{j2\pi f n}$，可现实里的声音是实数正弦 $\cos(2\pi f n)$。结论还成立吗？

成立。利用欧拉公式 $\cos(2\pi f n) = \frac{e^{j2\pi f n} + e^{-j2\pi f n}}{2}$，真实余弦就是两个复指数（正频率和负频率）的平均。系统是线性的，所以分别对两个复指数乘以对应的 $H(f)$ 和 $H(-f)$ 再相加即可。结果仍然是同频余弦，只是幅度和相位被 $H(f)$ 修改了。**实数正弦波的处理结果跟复指数完全一致。**

---

到这里，推导完了。回头看，整条链条其实很朴素：

1. LTI 系统 = 卷积（第 5 篇）；
2. 把复指数塞进卷积；
3. 指数运算拆开，跟 $n$ 无关的部分自然聚成一坨；
4. 聚出来的那坨**恰好**是傅里叶变换的定义；
5. 所以"系统对频率 $f$ 的增益"这个数，**天生**就等于 $h$ 的傅里叶变换在 $f$ 处的值。

$$h[n] \quad\xrightarrow{\ \text{傅里叶变换}\ }\quad H(f)$$

所以这不是巧合，是必然。时域里那段回响 $h[n]$ 和频域里这条 EQ 曲线 $H(f)$，是一枚硬币的两面。

## 四、代码实战：把冲激响应"变成"一条 EQ 曲线

空谈无用。我们造一个最常见的滤波器——**低通滤波器**（用来滤掉高频"嘶嘶"底噪的那种），亲手看它的冲激响应长什么样、它的频率响应又长什么样，并验证二者是一次傅里叶变换的关系。

```python
import numpy as np
import matplotlib.pyplot as plt

fs = 16000  # 采样率 16 kHz

# ---------- 1. 设计一个低通滤波器，直接拿到它的冲激响应 h[n] ----------
# 用窗函数法造一个截止约 3kHz 的 FIR 低通(细节第15篇会讲,这里先当黑盒)
from numpy import sinc
N = 101                     # 抽头数(冲激响应长度)
fc = 3000                   # 截止频率 3 kHz
n = np.arange(N) - (N - 1) / 2
h = 2 * fc / fs * sinc(2 * fc / fs * n)      # 理想低通的冲激响应
h *= np.hamming(N)                           # 加窗,避免振铃
h /= h.sum()                                 # 归一化,直流增益=1

# ---------- 2. 冲激响应做 FFT,就得到频率响应 H(f) ----------
H = np.fft.rfft(h, 4096)                      # 补零到4096点,曲线更平滑
freqs = np.fft.rfftfreq(4096, 1 / fs)
mag_db = 20 * np.log10(np.abs(H) + 1e-12)     # 幅度转 dB, 这就是EQ曲线的纵轴

# ---------- 3. 画:左边时域的h[n], 右边频域的EQ曲线 ----------
fig, ax = plt.subplots(1, 2, figsize=(12, 4))
ax[0].stem(np.arange(N), h)
ax[0].set_title("Impulse Response  h[n]  (time domain)")
ax[0].set_xlabel("Sample n"); ax[0].set_ylabel("Amplitude")

ax[1].plot(freqs, mag_db)
ax[1].axvline(fc, color='r', ls='--', label='cutoff 3kHz')
ax[1].set_title("Frequency Response  |H(f)|  (the EQ curve)")
ax[1].set_xlabel("Frequency (Hz)"); ax[1].set_ylabel("Gain (dB)")
ax[1].set_ylim(-80, 5); ax[1].legend()
plt.tight_layout()
plt.show()
```

右图就是这个滤波器的"性格画像"：3 kHz 以下几乎 0 dB（原样通过），3 kHz 以上一路俯冲向下（大幅衰减）。这正是它"低通"的含义——**低频放行、高频掐掉**。而这条曲线，纯粹是左图那串 $h[n]$ 做一次 FFT 得来的，没有任何额外信息。

![左图为低通滤波器的冲激响应 h[n]（对称 sinc 加窗），右图为其 FFT 得到的幅频曲线：3 kHz 前平坦、3 kHz 后快速衰减，红色虚线标出截止频率](fig_10_1_1.png)

想亲耳听到效果？把一段带底噪的人声 `x` 跑 `y = np.convolve(x, h)`，那层高频"嘶嘶"声会明显被压下去——因为你用这条曲线，把高频区的增益按下去了。

## 五、回收第 5 篇的钩子：卷积为什么在频域变成乘法

第 5 篇结尾我埋了个钩子：时域里昂贵的卷积，到频域会变成简单的逐点乘法。

$$x * h \quad\xrightarrow{\ \text{傅里叶变换}\ }\quad X(f)\cdot H(f)$$

现在你已经有能力理解它了。想想第二节那条铁律：系统对**每一个频率**的正弦，只是各自缩放一下。那么把输入声音拆成一堆频率成分 $X(f)$ 后，系统的作用无非是——**在每个频率上，把该成分乘以这个频率的增益 $H(f)$**。

一个频率乘一个数，各频率互不干扰。这就是"频域相乘"：不是什么高深定理，而是"系统对每个频率独立缩放"这件事的直接翻版。

这也顺带解释了 EQ 的工作方式：**EQ 就是让你亲手画出 $H(f)$ 这条曲线，然后播放时把声音的频谱逐点乘上去。** 你在 8 kHz 抬 6 dB，就是把 $H(f)$ 在 8 kHz 处设成约 2 倍，播放时该频段的能量翻倍——齿音和空气感就出来了。

至于工程效率：把一段长卷积搬到频域做逐点乘法（借助 FFT），复杂度能从 $O(N^2)$ 降到 $O(N\log N)$。现代混响、快速卷积、分块卷积（overlap-add）全靠这一招，才能在你的笔记本上实时跑。

## 六、这在音频工程里，到底解决了什么问题

| 场景 | 频率响应在其中的角色 |
|------|--------------------|
| **EQ 均衡器** | 你拖的那条曲线就是 $H(f)$；播放即频谱逐点乘上它 |
| **低通/高通/带通滤波** | 用 $|H(f)|$ 的形状定义"放行哪段、掐掉哪段"，降噪、去隆隆声、抗混叠全靠它 |
| **扬声器/耳机测评** | 厂商给的"频响曲线"就是设备的 $|H(f)|$，平不平决定音染 |
| **相位与群延迟** | $\angle H(f)$ 决定各频率的延迟；线性相位滤波器可保波形不变形 |
| **快速卷积混响** | 把 IR 与干声搬到频域做乘法，实现实时长混响 |

> **一句话记住**：只要一个处理是 LTI 的，它对声音做的所有事，都写在 $H(f)$ 这条曲线里——它是滤波器的完整"逐频率增益表"。

## 七、埋一个钩子：这条曲线，能"自己长出来"吗

到这里，频率响应看着挺完美了。但它藏着一个盲区。

傅里叶变换（也就是这条 $H(f)$）只看虚轴上那些"永不衰减的纯正弦"。可现实里有一类系统——比如带**反馈**的混响、话筒离音箱太近时的**啸叫**——它们的行为不是"稳定地缩放某个频率"，而是让某个频率的能量**自己越滚越大，直到失控**。这种"会不会失控"的信息，光靠傅里叶变换那条曲线，是看不全的。

要看清它，我们得把傅里叶变换升级——不只看"纯正弦"，还要看"边振荡边增长/边衰减"的信号。这个加强版工具叫**拉普拉斯变换**，它会引出两个决定滤波器命运的东西：**极点**和**零点**。

下一篇，我们就去看看：滤波器的稳定性，到底从哪来。

## 本篇小结

- **频率响应 $H(f)$**：系统对每一个频率"放大/削弱多少、挪动多少"的完整表，就是 EQ 曲线本身。
- **来源**：它精确等于冲激响应 $h[n]$ 的傅里叶变换——时域回响与频域曲线是同一系统的两张照片。
- **LTI 铁律**：系统喂正弦、吐同频正弦，只改幅度和相位、绝不生新频率；这是频率响应能成立的根基。
- **卷积→乘法**：因为系统对每个频率独立缩放，时域卷积在频域就成了逐点乘法，也是快速卷积和 EQ 的原理。
- **下一步**：傅里叶变换看不清"会不会失控"，拉普拉斯变换与极点零点将补上稳定性这块拼图。
