# 第 6 篇｜傅里叶级数：把"音色"拆成一堆纯音

> 一句话核心直觉：同样弹中央 C，钢琴和小提琴听起来天差地别——因为它们由**不同比例的谐波（泛音）叠加**而成。傅里叶级数就是写下"这个音色由哪些纯音、各占多少"的那张**配方表**。这一篇是频域之门的第一道门槛，所以我们照旧不满足于一个比喻，而要把它从**物理直觉、数学骨架、工程实现**三个角度都吃透——尤其要把"系数怎么算出来"亲手推一遍，而不是甩给你一堆积分。

---

## 一、先别看公式，我们先弹一个音

上一模块我们在山洞里拍了一下手，把时域里的卷积吃透了（第 5 篇）。现在推开频域之门，第一个要回答的问题特别朴素：

**为什么钢琴的中央 C 和小提琴的中央 C，明明是同一个音高，听起来却完全是两回事？**

你可能脱口而出：音色不同嘛。对，但"音色不同"只是给现象起了个名字，什么也没解释。我们要往下挖一层：音色这东西，物理上到底是什么？

答案出乎意料地干净：

> 一个稳定的乐音，其实是**一大堆频率严格成整数倍关系的纯正弦波，按不同比例叠加**出来的。这些正弦波里，最低的那个决定你听到的**音高**，其余更高的那些决定你听到的**音色**。

钢琴的中央 C，基频约 261.6 Hz，同时还含有 523 Hz、785 Hz、1046 Hz…… 这一长串。小提琴的中央 C，基频同样约 261.6 Hz——所以你觉得它俩"一样高"——但那一长串高频成分的**强弱配比**完全不同，于是音色两样。

**傅里叶级数说的就是这件事：任何一个周期性的声音，都可以被唯一地拆成一组频率为基频整数倍的正弦波之和。** 拆出来的这份"每个频率各占多少"的清单，就是这个音色的配方表。

先记住这个画面。后面我们会看到，这张"配方表"是个便于起步的好比喻，但它也藏着一个会把人带沟里的陷阱——第六节我们会主动把这个台拆掉。直觉先从这里长出来。

## 二、物理角度：谐波列是被"边界"逼出来的

先把两个词理清楚，全篇都要用。

设基频为 $f_0$（决定音高）。那么频率为 $f_0, 2f_0, 3f_0, 4f_0, \dots$ 的这些成分，就叫**谐波 (harmonics)**：

- $f_0$：第 1 谐波，也叫**基波 (fundamental)**；
- $2f_0$：第 2 谐波；
- $3f_0$：第 3 谐波；
- ……

而"**泛音 (overtones)**"是乐手的说法，指基波**以上**的所有成分——第 1 泛音就是第 2 谐波，往上顺延。两套词说的是同一批频率，只是起点差一个。别被这个错位绊住：本篇一律用"第 $n$ 谐波"。

**为什么真实乐器会自动长出这一整列整数倍频率？** 这不是数学家规定的，而是发声体的物理边界逼出来的。

拿一根两端固定的琴弦。它两端被摁死，动不了——用工程话说，这是**边界条件**。弦能稳定振动的模式，只能是那些"两端恰好不动（是波节）"的驻波：

```
基波 f0    :  |___________|      半个波长塞满全弦    → 频率 f0
2次谐波 2f0:  |_____._____|      一个波长,中间多一个波节 → 频率 2f0
3次谐波 3f0:  |___.___.___|      一个半波长,两个波节    → 频率 3f0
```

半个波长、一个波长、一个半波长…… 弦长被切成 1 份、2 份、3 份，对应频率刚好是 $f_0, 2f_0, 3f_0$。任何"非整数倍"的振动都不满足两端不动的约束，很快就自己耗散掉了。于是**整数倍谐波列不是巧合，是边界条件筛出来的唯一幸存者**。管乐器里的空气柱、你喉咙里的声带，道理完全一样——都是有边界的振动体。

> **关键认知**：音高来自基频，音色来自谐波配比。这就是为什么你能在嘈杂里一耳朵认出钢琴还是小提琴——你的听觉系统天生在读那张"谐波配方表"。傅里叶级数只是把这张表用数学写了下来。

顺带解决一个你可能一直没想通的问题：为什么这些谐波叠一起"好听"、能融成一个音，而随便两个频率放一起就刺耳？因为整数倍关系让它们每隔一个基频周期 $T=1/f_0$ 就精确重合一次——叠加结果仍是一个周期为 $T$ 的稳定周期波。**这也正是傅里叶级数只对周期信号成立的根源**，记住这一点，第六节拆台要用。

### 2.1 落到语音：元音的音色也是一张谐波配方表

别以为这只是乐器的事。你未来天天要处理的**人声元音**，遵循的是同一套物理。发声时声带以基频 $f_0$（男声约 100–150 Hz，女声约 200–300 Hz）周期性开合，产生的正是一列 $f_0,2f_0,3f_0,\dots$ 的谐波——这就是你听到的音高。然后这列谐波穿过口腔、鼻腔这个"声道滤波器"，某些频段被腔体共鸣**放大**、某些被压低，塑造出一组鼓包，叫**共振峰 (formants)**。

关键在于：**"啊 /a/""衣 /i/""呜 /u/"的基频可以完全一样（同一个音高唱出来），区别全在共振峰把哪几根谐波顶了上去。** 换句话说，元音的辨识度不在音高，而在那张谐波配方表被声道"整形"成什么样子——和钢琴 vs 小提琴是一模一样的道理，只不过整形者从琴体换成了你的口腔。第 16 篇的源-滤波器模型、第 17 篇的 MFCC，本质都是在量化这张被声道整形过的配方表。所以本篇不是音乐课的闲篇，它是你语音特征工程的第一块地基。

## 三、数学角度：配方表长什么样，先把公式压到最低

物理直觉建立了，现在摆公式，但只摆一个，而且它就是上面那段话的直译。

一个周期为 $T$（基频 $f_0 = 1/T$）的信号 $x(t)$，可以写成：

$$x(t) = A_0 + \sum_{n=1}^{\infty} A_n \cos\!\big(2\pi n f_0 t + \varphi_n\big)$$

逐字翻译成人话：

- $n$：第几谐波（$n=1$ 是基波，$n=2,3,\dots$ 是各泛音）；
- $A_n$：**第 $n$ 谐波有多强**——配方表里的"用量"，决定音色；
- $\varphi_n$：第 $n$ 谐波的**相位**——它此刻的起跑位置（第 8 篇会专门讲这个被大多数人忽视、实则关键的量）；
- $A_0$：第 0 项，$n=0$ 时 $\cos$ 退化成常数，代表整段信号的**直流偏置**（平均值）。做音频时它通常是 0——声音是气压的**起伏**，均值为零——所以后面为省事常把它略掉，但心里要知道它在那儿；
- $\sum$：把所有谐波**加起来**，还原出完整音色。

那一组 $A_n$（每个频率的强度），画成一根根竖线，就是你在频谱仪上看到的**频谱**雏形。傅里叶级数干的活，本质就是从时域波形 $x(t)$ 反推出这组 $A_n$ 和 $\varphi_n$。

到这里为止，v1 版就止步了——把公式一亮，说一句"怎么反推教材会用积分算"，然后溜了。但这恰恰是最该讲清的地方。**这组 $A_n$ 到底怎么被算出来？** 下一节我们不跳过它，一步一停地把它推出来。你会看到那个吓人的积分，其实就是第 5 篇你已经会的"逐点相乘再累加"。

## 四、把系数推出来：用纯正弦当"探针"去问

这一节是全篇的骨架。我们要回答：给你一段周期波形，**怎么算出第 $n$ 谐波到底占多少**？我不会甩公式，我们从一个你会的操作出发，一步步逼出它。

先换个记法方便动手。任何一个 $A_n\cos(2\pi n f_0 t+\varphi_n)$，用三角展开都能拆成一个 $\cos$ 加一个 $\sin$（这一步只是代数，$a_n=A_n\cos\varphi_n$、$b_n=-A_n\sin\varphi_n$）：

$$x(t) = a_0 + \sum_{n=1}^{\infty}\Big[\,a_n\cos(2\pi n f_0 t) + b_n\sin(2\pi n f_0 t)\,\Big]$$

现在的目标很具体：**已知左边整段波形 $x(t)$，求出某一个特定的系数，比如第 3 个 $a_3$。** 其余无穷多个系数我们都不知道、也不想管，就想把 $a_3$ 单独拎出来。

### 4.1 先问：两个正弦相乘再累加，会得到什么

要拎出 $a_3$，得先掌握一件小工具。它是整套方法的全部秘密，我们先在**离散**世界里把它摸清楚——因为那正是你电脑里干的事：一串采样值逐点相乘再求和。

拿两个纯正弦，采样一个整周期，逐点相乘，再把乘积全加起来。分两种情况：

**情况 A：两个频率相同。** 比如都用 3 次谐波，$\sin(2\pi\cdot3f_0 t)$ 乘它自己：

```
sin值:   +  +  -  -  +  +  -  -   (随时间起伏)
平方后:   +  +  +  +  +  +  +  +   (负负得正,全是正数!)
累加  :   一个明显的大正数
```

同频相乘，等于每个点都取平方，全变正数，累加起来是个**大数**。它们"步调一致"。

**情况 B：两个频率不同。** 比如 3 次谐波乘 5 次谐波：

```
sin3:    +  +  -  -  +  +  -  -
sin5:    +  -  -  +  +  -  -  +
乘积 :    +  -  +  -  +  -  +  -   (正负交替)
累加  :   正负相消 → 0
```

不同频率相乘，正负值在一个公共周期里**恰好抵消成零**。它们"步调错开"。

别急着信 ASCII 图，我们拿真数字砸一遍。取一个周期切成 8 个采样点（$m=0..7$），算三次点乘求和，你在纸上或 REPL 里都能验：

```
sin1[m] = sin(2*pi*1*m/8):  0.00  0.71  1.00  0.71  0.00 -0.71 -1.00 -0.71
sin3[m] = sin(2*pi*3*m/8):  0.00  0.71 -1.00  0.71  0.00 -0.71  1.00 -0.71

同频 sum(sin1*sin1) = 0+0.5+1+0.5+0+0.5+1+0.5           = 4.0   (大数!)
异频 sum(sin1*sin3) = 0+0.5-1+0.5+0-0.5-1+0.5           = 0.0   (抵消!)
```

同频那趟每一项都非负（自己乘自己），攒出 4；异频那趟正负恰好两两勾销，落到 0。**这不是巧合，是采样点在圆周上均匀分布、异频向量方向相互均衡的必然结果。** 数字对上了，我们再信那条抽象规律。写成积分（在一个周期 $T$ 上积分，积分就是连续版的"累加"）：

$$\int_0^{T}\cos(2\pi m f_0 t)\cos(2\pi n f_0 t)\,dt = \begin{cases} T/2 & m=n \ (\neq 0)\\ 0 & m\neq n \end{cases}$$

$\sin$ 与 $\sin$ 同理；而 $\cos$ 与 $\sin$ 无论频率是否相同，乘起来在整周期上**永远**积成 0。你不用背这三条，只要记住那张 ASCII 图：**频率对上了就攒出大数，对不上就自己抵消掉。**

### 4.2 于是探针法自然浮现

有了这把工具，拎出 $a_3$ 的办法几乎是自己蹦出来的。

我想知道 $x(t)$ 里含多少 3 次余弦成分。那我就**拿一根标准的 3 次余弦 $\cos(2\pi\cdot 3 f_0 t)$ 当探针，去乘整个 $x(t)$，再在一个周期上累加（积分）**：

$$\int_0^T x(t)\,\cos(2\pi\cdot 3 f_0 t)\,dt$$

把 $x(t)$ 的展开式代进去，探针会逐项去乘里面的每一个谐波。根据 4.1 的两条铁律：

- 探针撞上**自己那一项**（$a_3\cos(2\pi\cdot3f_0t)$）：同频，积出 $a_3\cdot\dfrac{T}{2}$，**活下来**；
- 探针撞上**其它所有项**（$a_0$、$a_1$、$b_5$……全部）：异频（或 cos 撞 sin），统统积成 **0**，**全部阵亡**。

于是右边一整个无穷级数，被这根探针"筛"得只剩一项：

$$\int_0^T x(t)\cos(2\pi\cdot3f_0t)\,dt = a_3\cdot\frac{T}{2}$$

移项就得到：

$$\boxed{\,a_3 = \frac{2}{T}\int_0^T x(t)\cos(2\pi\cdot3f_0t)\,dt\,}$$

把 3 换成任意 $n$，就是傅里叶级数系数公式的全部：

$$a_n = \frac{2}{T}\int_0^T x(t)\cos(2\pi n f_0 t)\,dt,\qquad b_n = \frac{2}{T}\int_0^T x(t)\sin(2\pi n f_0 t)\,dt$$

> **关键认知**：教材里那个吓人的积分公式，不是天上掉下来的定义，是被正交性**逼出来的唯一解法**。它的全部含义就一句话——**拿一根已知频率的纯正弦当探针，去和信号逐点相乘再累加；对上了就攒出大数（那就是这个频率的强度），对不上就自己抵消成零。** 这和第 5 篇卷积的"错位相乘再相加"是同一套手上功夫，只是这里两个信号不错位、频率在变。

停一下，承认一下你的直觉：如果你觉得"这不就是把展开式反过来解一个方程组吗"——**你的感觉完全没错**。正交性的价值就在于，它让这个"无穷元一次方程组"不用联立求解，每个未知数都能被一根对应的探针**单独**捞出来，互不干扰。这是它唯一、但极其值钱的作用。

### 4.3 这个"探针"是第 7 篇棱镜的原型

多说一句，好把篇章串起来。上面这套"换不同频率的探针逐个去问"，正是第 7 篇傅里叶变换的核心机制——那里探针写成复指数 $e^{-j2\pi f t}$（一次同时携带 cos 和 sin 两个方向，好把相位一起算出来），频率 $f$ 从离散的 $nf_0$ 变成连续可调。**傅里叶级数是探针只能停在整数倍频率上的版本；傅里叶变换是探针能滑到任意频率的版本。** 记住这句，第 7 篇会轻松很多。

### 4.4 顺手把 cos/sin 打包成一个复指数

再往前走半步，帮你以后读文献不发怵。你会发现几乎所有资料写傅里叶级数用的都不是上面那对 $a_n,b_n$，而是一个更紧凑的复数形式：

$$x(t) = \sum_{n=-\infty}^{+\infty} c_n\,e^{\,j 2\pi n f_0 t},\qquad c_n = \frac{1}{T}\int_0^T x(t)\,e^{-j 2\pi n f_0 t}\,dt$$

别被 $e^{j\cdot}$ 和"从 $-\infty$ 求和"吓到，它跟前面那套是**同一个东西换了件衣服**。回顾第 3 篇的欧拉公式 $e^{j\theta}=\cos\theta+j\sin\theta$：一个复指数一次就同时带上了 cos 和 sin 两个方向。于是原来要用一对实数 $(a_n,b_n)$ 才能表达的"这根谐波的余弦分量多少、正弦分量多少"，现在被打包进**一个复数 $c_n$**：它的**模长 $|c_n|$ 就是这根谐波的强度（幅度）**，它的**幅角 $\angle c_n$ 就是相位 $\varphi_n$**。换算关系是 $c_n=\tfrac12(a_n-jb_n)$（$n>0$）。

那"负频率"$n<0$ 又是什么鬼？纯粹是记账对称：真实信号是实数，为了让一堆复指数加起来虚部恰好抵消、只剩实数，正频率那根必须配一根共轭的负频率伙伴（$c_{-n}=c_n^*$）。两根一凑，虚部消掉，还原成一个实实在在的余弦。所以负频率不神秘，是"用复数表达实信号"必然带出来的镜像。

> **关键认知**：$c_n$ 这个复数把"强度"和"相位"两件事装进了一个数——模长是配方表的用量，幅角是第 8 篇要讲的相位。这个复指数探针 $e^{-j2\pi nf_0t}$，就是第 7 篇傅里叶变换公式里那个 $e^{-j2\pi ft}$ 的原型，只差把离散的 $nf_0$ 换成连续的 $f$。你现在已经把第 7 篇的核心符号提前认全了。

## 五、先手算一个具体的：方波的配方表

抽象公式在手，但按方法论的规矩，抽象之前先拿一个具体的小例子把它跑通、验证成立，再信它。最经典的例子就是**方波**——一段在 $+1$ 和 $-1$ 之间硬切换的周期波。

方波是**奇对称**的（$x(-t)=-x(t)$，一个奇函数）。奇函数里不可能藏得住 $\cos$（cos 是偶的），所以所有 $a_n=0$，直流 $a_0$ 也是 0（正负半段面积相消）。**配方表里只剩 $b_n$，只用 sin 探针去问就够了。** 这一步"用对称性砍掉一半系数"是手算里最省力的技巧。

设周期 $T$，前半 $[0,T/2)$ 取 $+1$、后半 $[T/2,T)$ 取 $-1$。套 $b_n$ 公式：

$$b_n = \frac{2}{T}\int_0^T x(t)\sin(2\pi n f_0 t)\,dt = \frac{2}{T}\left[\int_0^{T/2}\!\!(+1)\sin(\cdot)\,dt + \int_{T/2}^{T}\!\!(-1)\sin(\cdot)\,dt\right]$$

这个积分不难，我们慢慢来，别跳步。用 $\omega_n=2\pi n f_0=2\pi n/T$ 记谐波角频率，$\int\sin(\omega_n t)\,dt=-\cos(\omega_n t)/\omega_n$。先算前半段：

$$\int_0^{T/2}\!\sin(\omega_n t)\,dt = \left[-\frac{\cos(\omega_n t)}{\omega_n}\right]_0^{T/2} = \frac{1-\cos(\omega_n T/2)}{\omega_n} = \frac{1-\cos(n\pi)}{\omega_n}$$

（因为 $\omega_n T/2 = (2\pi n/T)(T/2)=n\pi$。）后半段带负号，同样算一遍会得到 $-\dfrac{\cos(2n\pi)-\cos(n\pi)}{\omega_n}=\dfrac{\cos(n\pi)-1}{\omega_n}\cdot(-1)$，正好和前半段**同号相加**（负半段的负信号 × 后半区间，两个负号把它翻成和前半段一致的贡献）。两段合并、代回 $\omega_n=2\pi n/T$，前面还有 $2/T$ 的系数，$T$ 约掉，落地成一串干净的数：

$$b_n = \frac{2}{n\pi}\big(1-\cos n\pi\big) = \begin{cases} \dfrac{4}{n\pi} & n\ \text{为奇数}\\[4pt] 0 & n\ \text{为偶数}\end{cases}$$

那个 $1-\cos n\pi$ 是关键开关：$n$ 偶数时 $\cos n\pi=1$，括号=0，**偶次谐波整个消失**；$n$ 奇数时 $\cos n\pi=-1$，括号=2，留下 $4/(n\pi)$。于是得到方波配方表两条铁律：

> **方波 = 只含奇次谐波，且第 $n$ 谐波强度按 $\dfrac{4}{n\pi}$ 递减。**

代具体数看一眼（后面代码会原样打印出来对上）：

| 谐波 $n$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| $b_n=4/(n\pi)$ | 1.273 | 0 | 0.424 | 0 | 0.255 | 0 | 0.182 |

看，基波最响，往上每根奇次谐波按 $1/n$ 掉下去，偶次全空。**这张表就是方波的音色身份证。** 现在我们信这套公式了，下一节就让电脑把它画出来、合成出来，亲眼看谐波怎么叠出一个方波。

## 六、等等——真实语音的元音，真是严格周期吗？

到这儿"配方表"这个比喻已经很顺手了：一个音色 = 一张列着各谐波用量的表。但方法论有条铁律——**一个比喻用到底一定会害人**。现在就得主动把这张台拆掉，否则你会带着一个错误的心理模型走进语音岗。

拆台的问题很简单：**傅里叶级数的前提是信号严格周期、且无限长地重复下去。真实语音满足吗？**

摊开一段你录的"啊——"元音波形看看。它确实**看起来**一段一段挺像、有明显的周期性（那正是声带以基频开合的结果）。但：

- 它**有始有终**。你不可能把 $[0,T]$ 这一小段无限复制到 $\pm\infty$——那样得到的是一个永不停歇的假信号，不是你录的那句话。
- 它**一直在变**。元音刚稳住又滑向下一个辅音，基频随语调起伏，共振峰随口型移动。严格周期要求"每一个周期都和上一个一模一样"，真实语音从不满足。
- 就算是"稳态"元音，也只是**近似**周期——声带每次开合都略有抖动（这抖动本身还是嗓音识别的特征）。

所以说白了：**傅里叶级数给你的那张离散谱线配方表，只对"永远重复的理想乐音"精确成立。** 对真实语音直接套用，等于假装那 30 毫秒会永远循环下去——这是个善意的谎言。

那工程上怎么办？答案藏在"永远重复"这个假设的裂缝里：**既然一整句话不周期，那就切成足够短的小片，让每一小片短到近似不变、又长到装得下几个基频周期，在每一小片内假装它是周期的、做一次频率分析。** 把这些小片的分析结果沿时间排开，就是你未来天天要盯的**语谱图 (spectrogram)**。这套"切片—各自分析—拼起来"的手法叫**短时分析 / 短时傅里叶变换 (STFT)**，是第 13 篇的主角，也是全部现代语音特征（第 17 篇的 MFCC 等）的地基。

> **关键认知**：傅里叶级数（离散谱线）↔ 严格周期信号；傅里叶变换（连续谱，第 7 篇）↔ 非周期但静止的整段信号；STFT（第 13 篇）↔ 真实会变化的语音。**"配方表"这个比喻的边界，就在"这段声音是否真的会永远重复"这里。** 越界了，就得换工具。别让一个漂亮比喻替你把这条边界抹掉。

## 七、代码实战：亲手看谐波涌现，并合成一个音色

空谈无益。我们用方波把前面推的公式跑出来，做三件事：一根根谐波往上叠看波形怎么逼近方波、画出配方表、合成一段能听的声音。下面这段是完整可运行的（NumPy + Matplotlib + SciPy，直接 `python` 跑），配图就是它生成的。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.io import wavfile

fs = 44100          # 采样率
f0 = 220.0          # 基频 220Hz (小字组 A 附近)
dur = 1.0
t = np.arange(int(fs * dur)) / fs

# ---------- 方波 = 奇次谐波按 4/(n*pi) 叠加 ----------
def square_partial(n_harmonics):
    """把前 n_harmonics 个奇次谐波叠起来, 第 n 谐波幅度 4/(n*pi)"""
    y = np.zeros_like(t)
    for k in range(n_harmonics):
        n = 2 * k + 1                                  # 奇数谐波: 1,3,5,7...
        y += (4.0 / (n * np.pi)) * np.sin(2 * np.pi * n * f0 * t)
    return y

ideal = np.sign(np.sin(2 * np.pi * f0 * t))            # 理想方波做参考

# ---------- 1. 一根根奇次谐波叠加, 逼近方波 ----------
fig, ax = plt.subplots(4, 1, figsize=(10, 9), sharex=True)
show = 900                                             # 只画前 900 个样本看细节
for i, N in enumerate([1, 3, 8, 50]):
    y = square_partial(N)
    ax[i].plot(t[:show], ideal[:show], "--", color="0.7", lw=1, label="ideal square")
    ax[i].plot(t[:show], y[:show], color="#c0392b", lw=1.4, label=f"{N} harmonic(s)")
    ax[i].set_title(f"sum of first {N} odd harmonic(s)")
    ax[i].set_ylabel("amp"); ax[i].legend(loc="upper right", fontsize=8)
ax[-1].set_xlabel("Time (s)")
plt.tight_layout(); plt.savefig("fig_06_1_1.png", dpi=110); plt.close(fig)
```

跑完看这张图，一个几乎让人上瘾的画面：**只有 1 根谐波时是光滑正弦；加到 3 根，肩膀开始变方；加到 8 根，已像模像样；加到 50 根，一个棱角分明的方波跃然纸上**（边角那点甩不掉的小抖动叫**吉布斯现象**，是有限项逼近尖锐跳变时的固有副产品，加再多谐波它都在，只是越挤越窄）。

![奇次谐波逐根叠加，波形从正弦逼近方波](fig_06_1_1.png)

这张图就是傅里叶级数最直观的证据：**方波不是"另一种波形"，它就是一堆正弦按 $4/(n\pi)$ 配方叠出来的。** 再把配方表本身画出来：

```python
# ---------- 2. 画方波的配方表(离散谱): 每根谐波的强度 ----------
harmonics = np.arange(1, 20)
amps = np.where(harmonics % 2 == 1, 4.0 / (harmonics * np.pi), 0.0)  # 偶次为0

fig2, ax2 = plt.subplots(figsize=(10, 4))
ml, sl, bl = ax2.stem(harmonics * f0, amps, basefmt=" ")
plt.setp(sl, color="#2c3e50"); plt.setp(ml, color="#c0392b")
ax2.plot(harmonics * f0, 4.0 / (harmonics * np.pi), ":", color="0.6", lw=1,
         label=r"$4/(n\pi)$ envelope")
ax2.set_title("Recipe of a square wave: harmonic amplitudes (odd only)")
ax2.set_xlabel("Frequency (Hz)"); ax2.set_ylabel("amplitude"); ax2.legend()
plt.tight_layout(); plt.savefig("fig_06_2_1.png", dpi=110); plt.close(fig2)

# 打印前几个系数,和第五节手算的表对一下
print([round(4.0/(n*np.pi), 4) if n % 2 else 0.0 for n in range(1, 8)])
# -> [1.2732, 0.0, 0.4244, 0.0, 0.2546, 0.0, 0.1819]  和手算表完全一致
```

![方波的配方表：奇次谐波按 4/(nπ) 递减，偶次为零](fig_06_2_1.png)

一排高度按 $1/n$ 递减的竖线，偶数谐波位置全空——**和第五节手算的表一个不差**。这就是把公式落到代码、再落回配图的闭环：推导、手算、程序，三处结果对齐，你才真敢信它。

```python
# ---------- 3. 合成能听的声音, 写成 wav ----------
tone = square_partial(50)
tone = np.int16(tone / np.max(np.abs(tone)) * 32767 * 0.8)   # 归一化留 headroom
wavfile.write("square_220.wav", fs, tone)
```

放出来听，那种略带嗡嗡、偏"电子"的音色，就是丰富奇次谐波的听感。试着改配方：把 `4/(n*pi)` 换成 $1/n^2$ 那类衰减更快的（三角波配方），高频立刻变柔；或者只留前 3 根谐波，音色就发闷。**你现在做的这件事，就是加法合成 (additive synthesis)。**

### 7.1 工程角度：CPU 到底怎么一个一个算这些系数

上面 `square_partial` 是"已知配方、正向合成"。但工程里更常见的方向是**反过来**：手里有一段录音，要**分析**出它的配方表。这一步 CPU 干的活，就是第四节那个积分的离散版——把积分换成对采样点的求和：

$$a_n \approx \frac{2}{N}\sum_{m=0}^{N-1} x[m]\cos\!\Big(2\pi n \frac{m}{N}\Big),\qquad b_n \approx \frac{2}{N}\sum_{m=0}^{N-1} x[m]\sin\!\Big(2\pi n \frac{m}{N}\Big)$$

其中 $N$ 是一个周期内的采样点数。翻译成机器动作：**为第 $n$ 个系数，生成一根 $n$ 次的 cos 探针（$N$ 个点），和录音那 $N$ 个点逐样本相乘，把乘积累加，最后乘 $2/N$。** 一个系数就是一趟"点乘 + 求和"，$N$ 次乘加。要 $K$ 个谐波，就 $K$ 趟，总成本约 $O(KN)$ 次乘加。

这里有三个一线工程师会立刻看出的坑：

- **成本与实时**：朴素地一根探针一根探针地算，$K$ 和 $N$ 都大时是 $O(KN)$，很贵。这正是 **FFT** 存在的理由——它用分治把"算一整套系数"从 $O(N^2)$ 压到 $O(N\log N)$（第 13 篇）。你现在写的这个双重循环，就是 FFT 要替你消灭的东西。
- **定点溢出**：合成时把 50 根谐波直接相加，峰值可能冲过 1.0；写进 int16 前**必须归一化并留 headroom**（上面代码乘了 `0.8`）。这和第 5 篇卷积合成时防削顶是同一类问题——多个成分叠加，峰值会长。别用 `int16` 的满量程去装未归一化的和，一定削顶。
- **对齐 / 一个周期到底是几个样本**：$N=f_s/f_0$ 常常不是整数（$44100/220\approx200.45$）。若你硬取 200 个点当"一个周期"去积分，探针和信号就对不齐，正交性不再精确成立，算出的系数会渗进本不该有的邻近谐波——这类"频谱泄漏"是第 13 篇加窗要处理的问题。**差半个样本，配方表就脏了**，和驱动层差一个样本的对齐 bug 是一个味道。

### 7.2 加法合成器：直接拿这张配方表实时"画"音色

反过来，正向合成在工程里就是**加法合成器**。经典的 Hammond 风琴前面板那排"抽屉音栓 (drawbars)"，每根滑块就是一个 $A_n$——你推拉滑块，就是在**实时编辑这张配方表**，合成器按 $\sum_n A_n\cos(2\pi n f_0 t+\varphi_n)$ 把波形算出来送进 DAC。

它的实时账很好算：每个输出样本要累加 $K$ 个谐波，就是 $K$ 次乘加/样本。$f_s=48\,\text{kHz}$、$K=64$ 根谐波，每秒约 $48000\times64\approx300$ 万次乘加——现代 CPU 毫无压力，所以加法合成能轻松实时跑。延迟也几乎为零：它是**逐样本即时生成**，不像 FFT 那样要攒够一帧才能出结果（第 13 篇会看到帧长直接换算成延迟）。工程上更省的做法是查表（wavetable）：预存一个周期的波形，运行时按相位查表，把乘加换成读内存。

一张对照表，把这张配方表在音频工程里到底解决什么问题钉死：

| 技术 | 背后就是傅里叶级数的思想 |
|------|------------------------|
| **加法合成器**（Hammond 风琴、各类 additive synth） | 给你一排谐波滑块，亲手调配方表来"画"音色 |
| **乐器音色识别 / 音源分离** | 不同乐器的谐波配比就是身份特征，机器读这张表来区分声源 |
| **谐波失真分析 (THD)** | 功放、编解码器的非线性会凭空长出本不该有的谐波，测这些多余谐波占比就是 THD |
| **基频检测 (Pitch Detection)** | 谐波列的间距就是基频，找到间距就找到音高，是变调、自动修音的第一步 |
| **物理建模合成** | 弦、管的驻波模式直接决定谐波列，反过来用这套关系合成逼真乐器 |

> **一句话记住**：在音频世界里，**"一个稳定的乐音"数学上永远等于"一组谐波正弦的加权和"。** 你以后每调一次 EQ、每分析一次音色、每做一次修音，脑子里都可以浮现出那张按频率排开的配方表——但别忘了第六节的边界：它只对"会重复的声音"精确成立。

### 7.3 一个数字世界的坑：谐波不能无限加

第七节代码里我们写 `range(n_harmonics)` 加了 50 根谐波，跑得好好的。但那个 220 Hz 方波，第 50 根**奇次**谐波已经到 $99\times220\approx21.8$ kHz。假如我贪心加到第 200 根，频率就冲到 $399\times220\approx87$ kHz——**远超采样率 44.1 kHz 的一半（22.05 kHz）**。

数学上的傅里叶级数是无穷项的，理想方波要用到无限高的谐波才棱角分明。但你的**采样系统装不下**：任何超过 $f_s/2$（奈奎斯特频率）的成分，采样时会被折叠回低频，变成本不存在的鬼音——这就是**混叠 (aliasing)**，第 9 篇采样定理的主角。一个 220 Hz 方波如果直接无脑加满谐波再采样，那些超过 22 kHz 的高次谐波会折回来，在频谱里凭空冒出一堆不谐和的杂音，听感发脏。

所以真实的合成器不会傻加：要么只加到奈奎斯特以下（**band-limited synthesis**），要么用 BLIT/BLEP 这类专门算法把跳变做成带限的。这就是"数学上的无穷级数"和"能跑在 48 kHz 工程系统上的有限实现"之间那道必须迈过的坎。

> **关键认知**：傅里叶级数在数学上是无穷项，但在采样率 $f_s$ 的数字系统里，你最多只能保留频率低于 $f_s/2$ 的那些谐波——再高的加进去不是更精确，而是折叠成混叠杂音。为什么是 $f_s/2$、混叠具体怎么发生，第 9 篇采样定理讲透。

## 八、埋一个钩子：把周期拉到无穷大会发生什么

傅里叶级数很美，但它那个硬前提——信号必须**周期、无限重复**——第六节我们已经承认了：真实语音不满足。那对一段**非周期**、活生生的声音，我们还能不能问"它含哪些频率、各占多少"？

能。而且方法惊人地自然，就藏在配方表的结构里。回看第七节那张配方表：谱线间距正好是 $f_0=1/T$。现在做个思想实验——**把周期 $T$ 一路拉长**：

- $T$ 变大，间距 $f_0=1/T$ 就变小，相邻谱线越挨越近；
- $T\to\infty$（信号不再重复，成了一段独一无二的声音），谱线密到糊成一片，**一根根离散的竖线连成一条连续的曲线**。

于是离散的"配方表"升级成连续的**频谱**，求和 $\sum$ 变成积分 $\int$，探针从"只能停在整数倍频率"松绑成"能滑到任意频率"。这就是下一篇要推开的门：

> **傅里叶变换 = 周期拉到无穷大的傅里叶级数。** 它是一把棱镜，能把任意一段声音（不只是周期乐音）分解成它的频率成分。

第 7 篇见。到那时你会发现，你今天推的"探针法"原封不动地在那里等着你，只是探针的频率不再离散了。

## 本篇小结

- **音高 vs 音色**：音高由基频决定，音色由谐波（泛音）的强弱配比决定。
- **谐波列是被逼出来的**：两端固定的弦等发声体，边界条件只允许整数倍频率的驻波存活，谐波列自然涌现——不是巧合。
- **三个角度看同一件事**：物理上是边界筛出的整数倍驻波叠加；数学上是"用纯正弦探针逐点相乘再累加、靠正交性把每个系数单独捞出来"（$a_n=\frac2T\int x\cos$）；工程上是一趟趟点乘求和（$O(KN)$），或反过来用加法合成器实时叠谐波。
- **系数不是甩出来的，是被正交性逼出来的**：同频叠加、异频抵消，让无穷元方程组的每个未知数都能被对应探针单独筛出。这和第 5 篇卷积的"错位相乘再相加"是同一套手上功夫。
- **方波实证**：只含奇次谐波、强度按 $4/(n\pi)$ 递减；手算、推导、代码、配图四处结果对齐。
- **比喻的边界**："配方表"只对严格周期信号成立；真实语音要短时分析（STFT，第 13 篇），别越界。
- **工程坑**：合成叠加要归一化留 headroom 防溢出；一个周期非整数样本会破坏正交性、造成频谱泄漏（第 13 篇加窗）；朴素 $O(KN)$ 的系数计算正是 FFT（第 13 篇）要替你消灭的；谐波不能无脑加满，超过 $f_s/2$ 会混叠（第 9 篇）。
- **落到语音**：元音的辨识度不在音高，在声道把哪几根谐波顶成共振峰——这张被声道整形过的配方表，是第 16、17 篇语音特征的地基。
- **下一步**：把周期拉到无穷大，离散谱线连成连续频谱——傅里叶变换（第 7 篇）。
