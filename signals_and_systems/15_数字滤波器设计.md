## 二、两种性格：FIR 与 IIR

回顾第 14 篇的差分方程，滤波器就两大门派，区别只在一个字：**反馈**。

### FIR：只看输入的老实人

FIR（Finite Impulse Response，有限冲激响应）**只用输入**：

$$y[n] = b_0 x[n] + b_1 x[n-1] + \dots + b_M x[n-M]$$

没有 $y[n-1]$ 这样的反馈项。它的性格：

- **绝对稳定**：没有反馈，输出不可能自己滚大。z 平面上它**没有极点**（除了原点），永远不会自激。
- **可以做到完美线性相位**：所有频率延迟一致，不会让波形变形——这对音频（尤其要求相位精确的场合）是巨大优点。
- **代价是"笨重"**：想要陡峭的过渡带，需要很多很多个系数（几十上百个 $b$），计算量大、延迟高。

还记得第 5 篇吗？**一个 FIR 滤波器的系数 $b$，本质上就是它的冲激响应 $h[n]$。** 滤波就是输入和这串系数做卷积。FIR 和卷积是同一件事的两个名字。

### IIR：带反馈记忆的高效者

IIR（Infinite Impulse Response，无限冲激响应）**用了反馈**：

$$y[n] = b_0 x[n] + \dots - a_1 y[n-1] - a_2 y[n-2] - \dots$$

有了 $y[n-k]$ 这些反馈项，它的性格正好相反：

- **极其高效**：靠反馈，往往只需 2~4 个系数就能做出 FIR 需要几十个系数才能达到的陡峭曲线。模拟滤波器（巴特沃斯、切比雪夫）的数字版几乎都是 IIR。
- **要操心稳定性**：有极点，极点必须待在单位圆内（第 14 篇），否则自激。
- **相位非线性**：不同频率延迟不同，会让波形轻微变形（多数音频场合可接受）。

一句话对照：

| | FIR（老实人） | IIR（高效者） |
|---|---|---|
| 反馈 | 无 | 有 |
| 稳定性 | 天生稳定 | 需保证极点在单位圆内 |
| 系数数量 | 多（几十~上百） | 少（常 2~5 个） |
| 相位 | 可做到完美线性 | 一般非线性 |
| 冲激响应 | 有限长（就是系数本身） | 无限长（拖尾衰减） |
| 音频典型用途 | 线性相位 EQ、卷积混响、抗混叠 | 参数 EQ、实时低/高通、混响内核 |

**做 EQ 时，业界主力是 IIR**——因为一个 EQ 往往有很多个频段，每个频段都得高效。经典的 EQ 每个频段就是一个**二阶 IIR（biquad）**，两个极点两个零点，四五个系数搞定。下面我们就从最基础的低通/高通开始，一路做到峰值 EQ。

## 三、先动手：设计并实现一个低通、一个高通

先不谈手推系数（那是教材折磨你的地方），我们直接用 `scipy.signal` 把设计做出来、跑起来、看效果——工程师就该这么干。设计滤波器你只需告诉它三件事：**类型（低通/高通）、截止频率、阶数（越高越陡）**。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

fs = 16000

# ---------- 设计一个 IIR 巴特沃斯低通(截止 1000Hz)和高通(截止 3000Hz) ----------
# butter 返回 (b, a) 差分方程系数; Wn 是归一化频率(相对奈奎斯特 fs/2)
b_lp, a_lp = signal.butter(N=4, Wn=1000 / (fs / 2), btype="low")
b_hp, a_hp = signal.butter(N=4, Wn=3000 / (fs / 2), btype="high")

# ---------- 画出两者的频率响应 ----------
def plot_response(b, a, label, ax):
    w, h = signal.freqz(b, a, worN=2048, fs=fs)      # freqz 直接给频率响应
    ax.plot(w, 20 * np.log10(np.abs(h) + 1e-9), label=label)

fig, ax = plt.subplots(figsize=(10, 5))
plot_response(b_lp, a_lp, "Low-pass @1kHz (4th order)", ax)
plot_response(b_hp, a_hp, "High-pass @3kHz (4th order)", ax)
ax.axhline(-3, color='gray', ls='--', alpha=0.6, label="-3 dB")
ax.set_xlim(0, fs / 2); ax.set_ylim(-60, 5)
ax.set_xlabel("Frequency (Hz)"); ax.set_ylabel("Gain (dB)")
ax.set_title("Butterworth low-pass & high-pass frequency response")
ax.legend(); ax.grid(True, alpha=0.3)
plt.tight_layout(); plt.show()
```

![四阶巴特沃斯低通（截止 1kHz）与高通（截止 3kHz）的频率响应：两条曲线在各自截止频率处越过 -3dB 线后向阻带下滑，展示阶数决定过渡带陡峭度](fig_15_1_1.png)

看这张图：低通在 1000 Hz 附近开始往下掉、高频被压到 -40dB 以下；高通反过来，3000 Hz 以下被砍。把 `N=4` 改成 `N=8`，过渡带会明显变陡——这就是"阶数越高越陡"的直观含义（代价是极点更多、延迟更大、越靠近失稳）。

**真正把滤波器"用"到信号上，只要一行**（`lfilter` 就是在跑那条差分方程）：

```python
# x 是你的输入信号(下一节会用真实录音)
# y_lp = signal.lfilter(b_lp, a_lp, x)
```

> **一个专业提醒**：高阶 IIR 直接用 `(b, a)` 形式在定点或长链路里容易因数值误差失稳。生产中更稳的做法是用二阶节级联（SOS）：`signal.butter(..., output='sos')` 配 `signal.sosfilt`。原理不变，只是把一个高阶滤波器拆成若干个稳定的 biquad 串起来。

## 四、EQ 的核心零件：峰值滤波器 (peaking biquad)

低通高通是"一刀切"，但真正的 EQ 要做的是**在某个中心频率把一段频率提升或衰减一定 dB**（比如"3kHz 提升 6dB 增加清晰度"，"250Hz 衰减 4dB 去除浑浊"）。这种"某频段隆起或凹陷"的滤波器叫**峰值滤波器 (peaking filter)**，是参数 EQ 的核心零件。

它就是一个二阶 IIR（biquad），由三个参数完全决定，全是调音师的语言：

- **中心频率 $f_0$**：要动哪个频率；
- **增益 $G$（dB）**：提升还是衰减、多少 dB（正提升、负衰减）；
- **品质因数 $Q$**：这个隆起/凹陷有多窄（$Q$ 越大越尖锐、影响的频率范围越窄）。

它的系数有一套业界公认的闭式公式（来自 Robert Bristow-Johnson 的 Audio EQ Cookbook，几乎所有 EQ 插件都在用）。你不需要背，但要知道它就是一组直接能算的 $b$、$a$：

```python
def peaking_eq(fs, f0, gain_db, Q):
    """RBJ Audio EQ Cookbook 的峰值滤波器,返回 (b, a) biquad 系数"""
    A = 10 ** (gain_db / 40)           # 增益转线性(注意峰值用的是 /40)
    w0 = 2 * np.pi * f0 / fs
    alpha = np.sin(w0) / (2 * Q)
    cosw = np.cos(w0)

    b0 = 1 + alpha * A
    b1 = -2 * cosw
    b2 = 1 - alpha * A
    a0 = 1 + alpha / A
    a1 = -2 * cosw
    a2 = 1 - alpha / A
    b = np.array([b0, b1, b2]) / a0    # 归一化(除以 a0)
    a = np.array([1.0, a1 / a0, a2 / a0])
    return b, a
```

短短几行，就是一个专业 EQ 频段的全部数学。$G>0$ 时它在 $f_0$ 处隆起一个峰、$G<0$ 时挖一个坑，$Q$ 控制宽窄。

## 五、实战：把一个三频段 EQ 装到真实录音上

现在把零件组装成成品。一个多频段 EQ，就是**把若干个 biquad 串联**（一个的输出喂给下一个）——串联在频域上等于各段增益相加，正好实现"这几个频段各自提升/衰减"。

下面这段代码是完整可跑的：读入一段录音（没有就用合成的宽频信号兜底），造一个三频段 EQ（低频衰减、中频提升、高频提升），处理它，再画出处理前后的频谱对比。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal
from scipy.io import wavfile

fs = 16000

# ---------- 读入真实录音;读不到就合成一段宽频测试信号 ----------
try:
    fs, x = wavfile.read("voice.wav")               # 换成你的录音路径
    if x.ndim > 1:                                  # 立体声转单声道
        x = x.mean(axis=1)
    x = x.astype(np.float64)
    x /= np.max(np.abs(x)) + 1e-9                   # 归一化
except Exception:
    # 兜底:白噪声(含全频段能量,便于看清 EQ 曲线)
    print("未找到 voice.wav,改用白噪声演示")
    x = np.random.randn(fs * 3) * 0.1

# ---------- 定义三频段 EQ ----------
# (中心频率 Hz, 增益 dB, Q)
bands = [
    (200,  -6.0, 0.9),   # 低频衰减 6dB: 去浑浊
    (2500, +5.0, 1.2),   # 中高频提升 5dB: 增加清晰度/临场感
    (6000, +4.0, 1.0),   # 高频提升 4dB: 增加空气感
]

def apply_eq(sig, fs, bands):
    y = sig.copy()
    for f0, g, q in bands:
        b, a = peaking_eq(fs, f0, g, q)
        y = signal.lfilter(b, a, y)      # 逐段串联处理
    return y

y = apply_eq(x, fs, bands)

# ---------- 对比处理前后的整体频谱 ----------
def avg_spectrum_db(sig, fs, nfft=2048):
    f, Pxx = signal.welch(sig, fs=fs, nperseg=nfft)   # 平滑的功率谱估计
    return f, 10 * np.log10(Pxx + 1e-12)

f1, S_in  = avg_spectrum_db(x, fs)
f2, S_out = avg_spectrum_db(y, fs)

# ---------- 画: (上)EQ目标曲线  (下)处理前后频谱 ----------
fig, ax = plt.subplots(2, 1, figsize=(10, 8))

# 上: EQ 的合成频率响应(把各段 freqz 的 dB 相加)
w = None; total = 0
for f0, g, q in bands:
    b, a = peaking_eq(fs, f0, g, q)
    w, h = signal.freqz(b, a, worN=2048, fs=fs)
    total = total + 20 * np.log10(np.abs(h) + 1e-9)
ax[0].plot(w, total, 'g', linewidth=2)
ax[0].axhline(0, color='gray', ls='--', alpha=0.5)
ax[0].set_title("EQ target curve (sum of 3 peaking bands)")
ax[0].set_xlim(20, fs / 2); ax[0].set_xscale('log')
ax[0].set_xlabel("Frequency (Hz)"); ax[0].set_ylabel("Gain (dB)")
ax[0].grid(True, which='both', alpha=0.3)

# 下: 处理前后的实际频谱
ax[1].semilogx(f1, S_in,  label="Before EQ", alpha=0.8)
ax[1].semilogx(f2, S_out, label="After EQ",  linewidth=2)
ax[1].set_title("Signal spectrum: before vs after EQ")
ax[1].set_xlim(20, fs / 2)
ax[1].set_xlabel("Frequency (Hz)"); ax[1].set_ylabel("Power (dB)")
ax[1].legend(); ax[1].grid(True, which='both', alpha=0.3)

plt.tight_layout(); plt.show()

# ---------- 写回文件,亲耳对比 ----------
y_out = y / (np.max(np.abs(y)) + 1e-9) * 0.95        # 防削波
wavfile.write("voice_eq.wav", fs, (y_out * 32767).astype(np.int16))
print("已输出 voice_eq.wav")
```

![三频段 EQ 效果：上图是三个峰值 biquad 串联叠加出的目标曲线（200Hz 挖坑、2.5kHz 与 6kHz 隆峰），下图处理前后的实测频谱在对应频段被压低或抬高，形状与目标曲线吻合](fig_15_4_1.png)

跑完你会得到三样东西：

1. **上图**——你设计的 EQ 目标曲线：200Hz 处一个 -6dB 的坑、2.5kHz 处一个 +5dB 的峰、6kHz 处一个 +4dB 的峰。这就是三个 biquad 串联叠加出的总响应。
2. **下图**——真实信号处理前后的频谱：你会看到处理后的曲线在 200Hz 附近整体压低、在 2.5kHz 和 6kHz 附近抬高，形状与上图的目标曲线严丝合缝。**这就是滤波器"真的按你的设计改变了声音的频率成分"的铁证。**
3. **voice_eq.wav**——用耳朵验收。如果输入是人声，你会听到低频的浑浊感减弱、咬字更清晰、高频更透亮。

> **想接着玩**：把 `bands` 改成你想要的任意组合，比如做一个"电话音效"（用低通+高通只留 300~3400Hz）、或一个去齿音的陷波（在 7~8kHz 放一个窄 Q 的负增益峰值）。你现在手里这套 `peaking_eq` + `apply_eq`，加上前几篇的低通/高通，已经是一个麻雀虽小五脏俱全的参数均衡器了。

## 六、设计时怎么选：一张决策表

| 需求 | 选 FIR 还是 IIR | 理由 |
|------|----------------|------|
| 多频段参数 EQ | **IIR (biquad)** | 每段只需 5 个系数，高效，业界标准 |
| 要求绝对不改变波形相位（母带、相位敏感场景） | **FIR（线性相位）** | 只有 FIR 能做到完美线性相位 |
| 实时低延迟低通/高通 | **IIR** | 低阶就够陡，延迟小 |
| 卷积混响、用实测 IR 做滤波 | **FIR** | IR 本身就是 FIR 系数（第 5 篇） |
| 抗混叠/抽取插值滤波器 | 常 **FIR** | 线性相位 + 稳定，重采样质量好 |

> **一句话记住**：EQ、实时低高通选 IIR（少系数、高效，但盯紧极点在单位圆内）；相位敏感或直接用冲激响应做滤波选 FIR（稳定、线性相位，但系数多、延迟大）。这个选择，本质就是在第 14 篇那张 z 平面地图上，权衡"要不要用极点（反馈）来省系数"。

## 本篇小结

- **FIR**：只看输入、无反馈、天生稳定、可做线性相位，但系数多、延迟大；系数本身就是冲激响应。
- **IIR**：带反馈、系数少、效率高、能做陡峭曲线，但要保证极点在单位圆内、相位非线性。
- **peaking biquad**：参数 EQ 的核心零件，由中心频率、增益、Q 三个调音语言参数决定，一组闭式公式直接算出系数。
- **多频段 EQ = 多个 biquad 串联**：串联即频域增益相加，实现各频段独立提升/衰减。
- **实战验证**：处理前后频谱对比 + 写回音频用耳朵验收，是滤波器"真的改变了声音"的铁证。
- **选型**：EQ/实时滤波用 IIR，相位敏感或用实测 IR 用 FIR——本质是权衡"要不要用反馈（极点）省系数"。
