# 第 14 篇｜Z 变换：把差分方程变成一张能读的地图

> 一句话核心直觉：第 11 篇里，拉普拉斯把模拟系统画成 $s$ 平面上的极点零点图，稳定判据是"极点在不在左半平面"。到了数字世界，声音是一串采样点、滤波器是一行差分方程——它有没有属于自己的那张地图？有，就是 **Z 变换**。它把那条"生死分界"的虚轴**卷成一个圆**：极点在单位圆内就稳、出了圆就自激。这一篇不满足于"$z^{-1}$ 就是延迟"这一个说法，而是把它从**物理直觉、数学骨架、工程实现**三个角度都吃透，顺带把 $s$ 平面、$z$ 平面、DTFT 单位圆这三张图的对应关系一次讲清。

---

## 一、承上：模拟世界有拉普拉斯，数字世界该拿什么导航

第 11 篇结尾我们把一张连续世界的地图交到你手里：拉普拉斯变换把模拟系统的微分方程变成 $s$ 平面上的**极点零点图**。极点在哪，系统就在哪个频率共振顶起一个包；零点在哪，那个频率就被砸下一个凹槽；而所有极点只要待在**左半平面**，系统就稳定，一旦有极点溜进右半平面，输出就指数增长、啸叫失控。那张 $s$ 平面图，是模拟滤波器工程师的导航地图。

可我们真正干活的地方，是数字世界。声音进了电脑就是一串 `float32` 采样点，滤波器不再是电阻电容，而是一行行代码里的**差分方程**：当前输出，等于当前和过去的输入、加上过去的输出，按一组系数加权组合。第 11 篇末尾我留了一个明确的问题：

> 离散世界里，还有没有"极点零点决定一切"这套地图？稳定判据还是"左半平面"吗？"沿虚轴走一遍读频响"这个动作，又会变成什么？

答案是：有，这张地图叫 **Z 变换**，坐标平面叫 **z 平面**。而且它跟 $s$ 平面几乎是一对孪生兄弟——只是那条决定生死的虚轴，会被**卷成一个圆**。第 12 篇你已经见过这个圆的影子了：DTFT 的 $X(e^{j\omega})=\sum_n x[n]e^{-j\omega n}$，那个 $e^{j\omega}$ 就是单位圆上的点。Z 变换，正是把 DTFT 里被钉死在单位圆上的探针，松绑成整个复平面。

这一篇的目标不是让你会背 $X(z)=\sum_n x[n]z^{-n}$，而是让你能**读**这张地图，并且看清它跟前两篇那两张图（$s$ 平面、DTFT 单位圆）到底怎么对上。我们按老规矩来：先建物理直觉，再把公式一步步推出来（从一个具体的一阶系统手算起步），然后落到工程——`ring buffer`、biquad 系数、定点量化把极点推出圆外的真实事故。

---

## 二、先别急着算求和：$z^{-1}$ 就是"回看一格"

翻开教材，Z 变换扑面而来的是这个求和：

$$X(z) = \sum_{n=-\infty}^{+\infty} x[n]\,z^{-n}$$

一个无穷求和，$z$ 还是个没说清楚是什么的复变量。当年我也是先被这个式子劝退的。但对做音频的人来说，Z 变换真正的入口不在这个求和，而在一个小得多、你其实**每天都在用**的东西：符号 $z^{-1}$。

**$z^{-1}$ 就是"延迟一个采样"这个动作。** 一个信号乘以 $z^{-1}$，等于把它整体往后推一拍：$x[n]$ 变成 $x[n-1]$。$z^{-2}$ 就是往后推两拍，$z^{-D}$ 推 $D$ 拍。就这么直白。

这个东西你太熟了。写实时音频处理，你手里总有一个 **ring buffer（环形缓冲区）**，每来一个新样本，你就往里塞，然后回头去取"上一个样本""上上个样本"。那个"回看一格"的动作，写成数学就是 $z^{-1}$；"回看 $D$ 格"就是 $z^{-D}$。

```
ring buffer:   ... x[n-3]  x[n-2]  x[n-1]  x[n]
                                     ↑              ↑
                                  z^{-1}         当前样本
                                (回看一格)
```

先记住这一件事，别的都能长出来。下面这条差分方程——一个最普通的滤波器：

$$y[n] = b_0\,x[n] + b_1\,x[n-1] + b_2\,x[n-2] - a_1\,y[n-1] - a_2\,y[n-2]$$

翻译成人话：

- $x[n], x[n-1], \dots$：现在和过去的**输入**采样，系数 $b$ 决定"参考多少输入、各回看几格"；
- $y[n-1], y[n-2], \dots$：过去的**输出**采样，也就是**反馈**，系数 $a$ 决定"参考多少自己的历史"。

（顺带对齐第 5 篇和第 15 篇的说法：只有输入项、没有反馈项（没有 $a$）的是 **FIR**，它的系数 $b$ 就是冲激响应 $h[n]$；带反馈项（有 $a$）的是 **IIR**。这两个名字第 15 篇会展开，本篇只需知道"有没有 $a$"这条分界。）

问题来了：给你一串 $a$、$b$ 系数，你能一眼说出这滤波器是低通还是高通吗？它稳不稳、会不会自激啸叫？盯着这行方程看不出来。我们需要把它变个形，变到一张能"看"的地图上。而搬过去的桥，就是把每一个"回看一格"都换成"乘一个 $z^{-1}$"。

## 三、从差分方程到传递函数：把延迟变成代数

这一节是全篇的骨架。我们不甩公式，而是先拿**一个具体的一阶系统**手算一遍，看清 $H(z)$ 是怎么被"逼"出来的，再抽象成通式。

### 14.1 先手算一个一阶系统，别碰通式

挑一个最小的带反馈系统：

$$y[n] = x[n] + 0.9\,y[n-1]$$

大白话读它：**当前输出 = 当前输入 + 上一次输出的 0.9 倍。** 这是个"带记忆的漏桶"——每来一个新样本就加进去，同时把上一刻的结果打个九折累上。你在做一阶低频提升、或者最简单的一极点平滑器时，写的就是这行。

先别急着变换，我们**手动喂一个冲激**进去，看它吐什么。输入 $x=\delta[n]=[1,0,0,0,\dots]$，初始时所有历史都是 0：

- $y[0] = x[0] + 0.9\,y[-1] = 1 + 0 = 1$
- $y[1] = x[1] + 0.9\,y[0] = 0 + 0.9\cdot 1 = 0.9$
- $y[2] = x[2] + 0.9\,y[1] = 0 + 0.9\cdot 0.9 = 0.81$
- $y[3] = 0.9\cdot 0.81 = 0.729$
- ……

看出来了吗？冲激响应是 $h[n] = 0.9^{\,n}$（$n\ge 0$），一条**永远衰减、但永远不严格等于 0** 的指数尾巴。这就印证了第 5 篇那句话：IIR 的 $h$ 原则上**无限长**。它只用一个反馈系数，就造出了一条无限长的响应——这正是反馈的省料之处。同时你也该有个预感：只要那个 0.9 变成 $\ge 1$，这条尾巴就不衰减反而越滚越大——稳定性问题已经在门口了，我们很快回来收它。

现在做 Z 变换。核心工具只有一条**延迟性质**：如果 $x[n]$ 的 Z 变换是 $X(z)$，那么延迟一拍的 $x[n-1]$，其 Z 变换就是 $z^{-1}X(z)$。（为什么？把 $x[n-1]$ 代进求和 $\sum_n x[n-1]z^{-n}$，换元 $m=n-1$，就得到 $z^{-1}\sum_m x[m]z^{-m}=z^{-1}X(z)$。延迟一拍 = 乘一个 $z^{-1}$，跟第二节那个直觉严丝合缝。）

对差分方程**两边**做 Z 变换。左边 $y[n]\to Y(z)$；右边 $x[n]\to X(z)$，$y[n-1]\to z^{-1}Y(z)$：

$$Y(z) = X(z) + 0.9\,z^{-1}Y(z)$$

**注意此刻发生了什么**：原来那条"这一拍依赖上一拍"的递推关系——一个你只能一个样本一个样本往下算的东西——变成了一条普普通通的**代数方程**。$n$ 消失了，卷积/递推消失了，只剩 $z$ 的代数。这就是 Z 变换真正的魔法，不是"延迟"，是**把时域的递推关系代数化**。

把 $Y(z)$ 归到一边：

$$Y(z) - 0.9\,z^{-1}Y(z) = X(z) \;\Longrightarrow\; Y(z)\,(1 - 0.9\,z^{-1}) = X(z)$$

于是**传递函数**——输出的 Z 变换比输入的 Z 变换——就解出来了：

$$H(z) = \frac{Y(z)}{X(z)} = \frac{1}{1 - 0.9\,z^{-1}}$$

### 14.2 读这个一阶结果：极点在 $z=0.9$，稳

$H(z)=\dfrac{1}{1-0.9z^{-1}}$ 这个分式，我们关心它什么时候爆掉——也就是分母等于 0 的地方。为了看清楚，把 $z^{-1}$ 换回正幂（分子分母同乘 $z$）：

$$H(z) = \frac{z}{z - 0.9}$$

分母 $z-0.9=0$，给出 $z = 0.9$。这个让 $H(z)\to\infty$ 的点，就是**极点**。分子 $z=0$ 给出一个**零点**在原点。

现在把这个极点画到 z 平面上：它落在实轴 $+0.9$ 处，**在单位圆内部**（$|0.9|<1$）。对照 14.1 手算出的 $h[n]=0.9^n$ 那条衰减尾巴——极点在圆内，冲激响应就衰减，系统**稳定**。极点的模 $|z|=0.9$ 正是那条指数尾巴每拍的衰减比例。这不是巧合，是同一件事：**极点的位置，直接编码了冲激响应衰减多快。**

> **第一个关键认知**：一个带反馈的差分方程，做 Z 变换后变成 $H(z)$ 这样一个关于 $z$ 的**分式**。分母的根就是极点。极点的模决定冲激响应衰减/增长的速度：模 < 1（圆内）衰减 → 稳定；模 = 1（圆上）不衰减；模 > 1（圆外）增长 → 失控。这跟 14.1 里我们手算的那条 $0.9^n$ 尾巴是完全一致的。

### 14.3 现在才抽象成通式

一阶的路走通了，通式就水到渠成。拿第二节那条一般差分方程，两边逐项做 Z 变换，每个 $x[n-i]$ 换成 $z^{-i}X(z)$、每个 $y[n-j]$ 换成 $z^{-j}Y(z)$：

$$Y(z)\big(1 + a_1 z^{-1} + a_2 z^{-2} + \dots\big) = X(z)\big(b_0 + b_1 z^{-1} + b_2 z^{-2} + \dots\big)$$

整理出传递函数：

$$\boxed{\,H(z) = \frac{Y(z)}{X(z)} = \frac{b_0 + b_1 z^{-1} + b_2 z^{-2} + \dots}{1 + a_1 z^{-1} + a_2 z^{-2} + \dots} = \frac{B(z)}{A(z)}\,}$$

别被分式吓住，它的意义特别朴素：**$H(z)$ 是一个关于 $z$ 的有理分式，而任何分式都由它的分子零点和分母零点完全决定。** 分子多项式 $B(z)$ 的根 = 零点，分母多项式 $A(z)$ 的根 = 极点。这就引出整张地图上仅有的两种地标。

顺便点破 FIR/IIR 在这张图上的样子：FIR 没有 $a$（分母 $A(z)=1$），所以**没有极点**（除了原点那种平凡的），全是零点——天然稳定，这跟第 11 篇说的"没反馈就没真极点"完全对得上。IIR 有 $a$，才有分母、才有极点，才可能失控。

## 四、极点与零点：地图上仅有的两种地标

$H(z)$ 这个分式，有两组特殊的点：

- **零点 (zeros)**：让**分子** $B(z)=0$ 的那些 $z$ 值。此处 $H(z)=0$——滤波器在这些位置**极力压制、掏空**能量。
- **极点 (poles)**：让**分母** $A(z)=0$ 的那些 $z$ 值。此处 $H(z)\to\infty$——滤波器在这些位置**极力放大、共振**。

把它们画在复平面（z 平面）上，零点用 ○、极点用 ×，就得到**极点零点图 (pole-zero plot)**。它是差分方程的"性格画像"，跟第 11 篇那张 $s$ 平面极零点图是同一套读法，只是底图从"半平面"换成了"圆"。

那怎么从这张图读出滤波器在**每个频率**上的行为？这就要请出 z 平面上最重要的一条线——**单位圆**。

### 14.4 单位圆：所有的频率都在这个圈上

z 平面上以原点为心、半径为 1 的那个圆，叫**单位圆**。它的地位无可替代，而它的来历，第 12 篇其实已经埋好了。

回忆 DTFT：$X(e^{j\omega})=\sum_n x[n]e^{-j\omega n}$。把它跟 Z 变换 $X(z)=\sum_n x[n]z^{-n}$ 摆在一起，一眼就看出——**DTFT 就是 Z 变换令 $z=e^{j\omega}$ 的特例。** 而 $e^{j\omega}$ 是什么？模长恒为 1、辐角为 $\omega$ 的复数，画在 z 平面上就是**单位圆上的一个点**。$\omega$ 从 0 转到 $\pi$，这个点就沿单位圆从最右边（$z=1$）逆时针走到最左边（$z=-1$）。

> **关键认知（三张平面的对应）**：DTFT 是 Z 变换在**单位圆上**取值的结果，正如第 11 篇里傅里叶是拉普拉斯在**虚轴上**取值的结果。$s$ 平面的那条虚轴 $j\omega$，映射到 z 平面就卷成了单位圆。这不是比喻，是 $z=e^{sT}$ 这个映射（$T$ 是采样周期）逼出来的——下一节专门讲这个映射怎么把三张图缝在一起。

有了这条线，读图规则简单到近乎作弊。单位圆上每个点对应一个真实频率：

- 从最右边 $z=1$ 出发是 **0 Hz（直流）**；
- 逆时针转到最左边 $z=-1$ 是 **奈奎斯特频率 $f_s/2$**；
- 绕半圈（上半圆）就扫过了这个数字系统能表示的全部正频率。

想知道某个频率处滤波器的增益？就站到单位圆上那个频率对应的点，看它**离各个极点、零点有多近**：

- **离极点越近 → 增益越大**（极点在拉高附近的响应）；
- **离零点越近 → 增益越小**（零点在压低附近的响应）。

于是整条频率响应曲线，不过是你**沿单位圆走一圈、一路感受"被极点拉高、被零点压低"的过程**。这跟第 11 篇"沿虚轴走一遍读地形"是同一个动作，只是把直线走法换成了绕圈走法——第 11 篇结尾预告的"虚轴卷成圆"，此刻兑现了。

想做低通？把极点放在 $z=1$（0 Hz）附近、把零点放在 $z=-1$（高频）附近——低频被拉高、高频被压死。这就是设计滤波器的几何直觉，第 15 篇会真的动手摆。

### 14.5 极点位置就是稳不稳：把第 11 篇的判据卷成圆

单位圆还管着另一件生死大事：稳定性。

- **所有极点都在单位圆内部**（模 < 1）→ 系统**稳定**，冲激响应衰减到 0（就像 14.1 那条 $0.9^n$）。
- **有极点落在单位圆上或跑到外部**（模 $\ge 1$）→ 系统**不稳定**，输出越滚越大、自激啸叫直到爆掉。

把它跟第 11 篇拉普拉斯的判据并排放，孪生关系一目了然：

| | 模拟世界（拉普拉斯，$s$ 平面） | 数字世界（Z 变换，$z$ 平面） |
|---|---|---|
| 探针 / 变量 | $s=\sigma+j\omega$（连续时间） | $z$（离散时间） |
| 频率轴 | 虚轴 $j\omega$ | **单位圆** $z=e^{j\omega}$ |
| 稳定区域 | **左半平面**（$\sigma<0$） | **单位圆内部**（$\lvert z\rvert<1$） |
| 频响怎么读 | 沿虚轴走一遍 | 沿单位圆走一圈 |
| 极点作用 | 共振 / 放大 | 共振 / 放大 |
| 零点作用 | 陷波 / 压制 | 陷波 / 压制 |

判据换了形状，逻辑一模一样：极点太靠外，反馈就失控。为什么"左半平面"会变成"圆内部"？下一节的 $z=e^{sT}$ 会给出精确答案。

## 五、$z=e^{sT}$：把三张平面缝在一起的那一针

前面反复说"虚轴卷成圆""左半平面变圆内"，这一节把它说死。为什么是这个对应？因为连续和离散之间隔着一个动作——**采样**。

一个连续的复指数探针 $e^{st}$，每隔 $T$ 秒（$T=1/f_s$ 是采样周期）采一个点，采出来的序列是：

$$e^{s\cdot nT} = \big(e^{sT}\big)^{n}$$

而离散世界里我们用的探针是 $z^n$。两者对上，就逼出了那个连接三张平面的映射：

$$\boxed{\,z = e^{sT}\,}$$

**采样这个动作，本身就是从 $s$ 平面到 $z$ 平面的一次坐标变换。** 现在把 $s=\sigma+j\omega$ 代进去，拆成模和辐角看：

$$z = e^{(\sigma+j\omega)T} = \underbrace{e^{\sigma T}}_{\text{模}}\cdot \underbrace{e^{j\omega T}}_{\text{辐角}}$$

一项一项读，三张图的对应关系全在这里：

- **模 $|z| = e^{\sigma T}$，由 $s$ 的实部 $\sigma$ 决定。**
  - $\sigma < 0$（$s$ 的左半平面，衰减）→ $e^{\sigma T} < 1$ → $z$ 落在**单位圆内**。左半平面 = 圆内，稳定判据就是这么对上的。
  - $\sigma = 0$（虚轴，纯振荡不增不减）→ $|z| = 1$ → $z$ 落在**单位圆上**。虚轴 = 单位圆。
  - $\sigma > 0$（右半平面，增长）→ $|z| > 1$ → $z$ 跑到**单位圆外**。右半平面 = 圆外，失控。
- **辐角 $\angle z = \omega T$，由频率 $\omega$ 决定。** 频率越高，$z$ 沿圆转得越远。转到 $\omega T=\pi$（即 $\omega=\pi/T=\pi f_s$，也就是奈奎斯特频率 $f_s/2$）时，$z=-1$，正好转到圆的最左边。

于是第 11 篇那条"生死分界线"虚轴，被 $z=e^{sT}$ 这个指数映射**弯成了一个圈**：左半平面那片无限大的稳定区，被卷进了单位圆里面这块有限的圆盘。三张图这样缝在一起：

```
 s 平面 (连续, 拉普拉斯)        --- z=e^{sT} 采样 --->     z 平面 (离散, Z 变换)
   左半平面(σ<0)  稳定                                     单位圆内部  稳定
   虚轴 jω        傅里叶/频率轴          ────卷成────>      单位圆      DTFT/频率轴
   右半平面(σ>0)  发散                                     单位圆外部  发散
```

> **关键认知**：不要把"$s$ 平面 / $z$ 平面 / DTFT 单位圆"当成三样东西。它们是同一套极零点地图在三种时间观下的样子——$s$ 平面是连续时间版（判据：左半平面），$z$ 平面是离散时间版（判据：单位圆内），DTFT 是这张离散地图**只沿单位圆切一刀**读出的频响曲线。采样（$z=e^{sT}$）负责在前两者之间换坐标，"取单位圆上的值"负责从 Z 变换降到 DTFT。

（一个诚实的边界：$z=e^{sT}$ 是**多对一**的映射——$s$ 平面上每隔 $2\pi/T$ 高的一条条水平带，都绕单位圆转满一圈映到同一个位置。这正是**频率混叠**在复平面上的样子，也是第 9 篇采样定理那件事的几何面孔。本篇不展开，你只需知道：单位圆能表示的频率到 $f_s/2$ 就绕完一圈了，再高的频率会叠回来。）

---

## 六、等一下：$z^{-1}$ 真的"只是延迟"吗

到这儿得停下来拆自己的台。前面第二节我把 $z^{-1}$ 说成"回看一格"，这个直觉好用，但**只用它会把你带沟里**。

$z^{-1}$ 确实是延迟一个采样，这没错。但请看清楚：$z$ 是一个**复数变量**，$H(z)$ 是定义在整个复平面上的**函数**。"延迟"只是 $z^{-1}$ 在时域里做的**一件事**，不是 $z$ 的全部身份。如果你只把它记成"延迟符号"，下面这些你就全看不见了：

- **$z=0.9$、$z=e^{j\omega}$、$z=1.02$ 这些具体取值意味着什么？** "延迟"这个说法根本没有"取值"的概念——延迟就是延迟，哪有 $z=0.9$ 一说。但正是"往 $z$ 里代不同复数值"这件事，才让我们能问"极点在哪""单位圆上增益多大""极点出没出圆"。$z$ 是个能取遍复平面的变量，这才是地图之所以是地图。
- **稳定性这个几何判断从哪来？** "延迟"里没有稳定不稳定。是因为 $H(z)$ 是复平面上的函数、极点是它的奇点、单位圆是频率轴，"极点在不在单位圆内"才成为一个**几何问题**。丢掉复变量视角，稳定性就无从谈起。
- **为什么差分方程能变代数？** 14.1 里最关键的一跳——递推关系 $\to$ 代数方程——靠的是"两边同乘、$z$ 当普通代数量运算"。这是把整个信号一次性变换到 $z$ 域的结果，不是"某一拍延迟一下"能概括的。

所以更准确的说法是：**$z^{-1}$ 在时域是"延迟一格"，但 Z 变换真正的威力，是把整条信号/整个差分方程搬进复平面，让"卷积/递推"变成"代数式"、让"稳不稳"变成"极点在不在圆内"的几何判断。** 延迟只是这套机器最表层的一个齿轮。

> **关键认知（比喻的边界）**：把 $z^{-1}$ 记成"延迟一格"，仅在你**写代码/搭延迟线**时够用；一旦要**分析**滤波器（读频响、判稳定、设计极零点），就必须切回"$z$ 是复变量、$H(z)$ 是复平面上的函数"这个视角。两个视角是同一个 $z^{-1}$ 的两面，缺了后者，Z 变换就退化成了一个花哨的延迟记号，那还不如直接写 $x[n-1]$。

## 七、收敛域 ROC：同一个 $H(z)$ 可以是两个不同的系统

这一节是严谨红线，很多入门讲义会跳过它，但跳过它你迟早会栽。

回到那个求和 $X(z)=\sum_n x[n]z^{-n}$。它是**无穷求和**，凭什么就一定收敛（加得出一个有限的数）？答案是：**不一定。** 只有当 $z$ 取在复平面某一片区域里时，这个和才收敛。这片让求和有意义的区域，叫**收敛域 (Region of Convergence, ROC)**。

用 14.1 那条 $h[n]=0.9^n$（$n\ge0$，因果）算给你看。它的 Z 变换是：

$$H(z)=\sum_{n=0}^{\infty}0.9^n z^{-n}=\sum_{n=0}^{\infty}\big(0.9\,z^{-1}\big)^n$$

这是个公比为 $0.9z^{-1}$ 的等比级数，收敛的条件是公比的模 < 1，即 $|0.9z^{-1}|<1$，也就是 $|z|>0.9$。收敛时求和 $=\dfrac{1}{1-0.9z^{-1}}$——正是我们之前解出的 $H(z)$。**所以完整的答案是：$H(z)=\dfrac{1}{1-0.9z^{-1}}$，ROC 是 $|z|>0.9$（极点之外的整个区域）。**

关键在这句话：**光写出 $H(z)$ 的那个分式还不够，必须连 ROC 一起给，才唯一确定一个系统。** 为什么？看这个经典对照。考虑一条左边序列（反因果，只在 $n<0$ 有值）$h_2[n]=-0.9^n$（$n\le -1$），你去算它的 Z 变换，会得到**一模一样**的分式 $\dfrac{1}{1-0.9z^{-1}}$——但它的 ROC 是 $|z|<0.9$（极点之内）。

同一个代数式，两个不同的 ROC，对应**两个完全不同的系统**：

| | ROC | 冲激响应长相 | 因果? | 稳定? |
|---|---|---|---|---|
| 系统 A | $\lvert z\rvert>0.9$（极点外） | $0.9^n$，向右、衰减 | 因果 | 稳定（ROC 含单位圆） |
| 系统 B | $\lvert z\rvert<0.9$（极点内） | 向左、$n\to-\infty$ 那侧 | 反因果 | 不稳定（ROC 不含单位圆） |

从这张表能榨出两条一线工程师必须钉死的判据：

- **因果性看 ROC 朝哪**：因果系统（只依赖当前和过去，这是实时音频的铁律）的 ROC 一定是**最外那个极点之外**的区域（$|z|>r_{\max}$）。
- **稳定性看 ROC 含不含单位圆**：一个系统 BIBO 稳定，当且仅当它的 **ROC 包含单位圆**。对因果系统，ROC 是 $|z|>r_{\max}$，要包含单位圆（$|z|=1$）就得 $r_{\max}<1$——**所有极点在单位圆内**。看，第 14.5 节那条"极点在圆内=稳定"的判据，其实是"因果 + ROC 含单位圆"这两条更底层规则的合体结果。

> **关键认知**：$H(z)$ 的**分式形状只告诉你极点零点在哪**，但没告诉你系统是"向右的因果衰减"还是"向左的反因果增长"——那个信息在 ROC 里。做实时音频我们几乎永远要**因果**系统，所以默认取"极点外"那个 ROC；这时"稳定"就干净利落地等价于"极点全在单位圆内"。这也是为什么前面几节可以放心地只谈极点位置——我们一直默认站在因果这块地上。

（第 11 篇里拉普拉斯也有 ROC，只是那里是"某条竖线 $\sigma=$ 常数的右边/左边"；到了 Z 域，"竖线的左右"变成了"某个圆的内外"——又一次，虚轴的直线逻辑卷成了圆的逻辑。）

## 八、工程落地：$z^{-1}$ 落到 ring buffer，$H(z)$ 落到代码

地图讲完了，落到你敲的代码。Z 变换最爽的一点是：**它跟代码之间几乎没有翻译损耗**。传递函数的系数，就是差分方程的系数，就是你程序里那个 `b[]`、`a[]` 数组。

### 8.1 biquad：照着 $H(z)$ 系数直接写实现

音频里最常用的 IIR 结构是**二阶节 (biquad)**——所有参量 EQ、低通、高通、峰值、搁架滤波器，本质都是一个或几个 biquad 串起来。它的传递函数就是我们通式取到二阶：

$$H(z)=\frac{b_0 + b_1 z^{-1} + b_2 z^{-2}}{1 + a_1 z^{-1} + a_2 z^{-2}}$$

对应的差分方程（把分母移回时域、解出 $y[n]$）：

$$y[n] = b_0 x[n] + b_1 x[n-1] + b_2 x[n-2] - a_1 y[n-1] - a_2 y[n-2]$$

翻译成一个样本一个样本的实时处理，$z^{-1}$/$z^{-2}$ 就是那几个"回看一格/两格"的状态变量：

```python
class Biquad:
    """一个二阶 IIR 节。系数 b0,b1,b2,a1,a2 由 H(z) 直接照抄。
       x1,x2 = 输入延迟线(z^-1, z^-2); y1,y2 = 输出延迟线(反馈)。"""
    def __init__(self, b, a):
        self.b0, self.b1, self.b2 = b          # 分子系数
        _, self.a1, self.a2 = a                # 分母系数(a0 已归一化为 1)
        self.x1 = self.x2 = 0.0                # 过去两个输入 = z^-1, z^-2
        self.y1 = self.y2 = 0.0                # 过去两个输出 = 反馈

    def process_sample(self, x):
        # 这一行就是差分方程, 也就是 H(z) 分子分母各项的逐字翻译
        y = (self.b0 * x + self.b1 * self.x1 + self.b2 * self.x2
             - self.a1 * self.y1 - self.a2 * self.y2)
        # 移位延迟线: 新样本挤进来, 旧的往后退一格(这就是 z^-1 的物理动作)
        self.x2, self.x1 = self.x1, x
        self.y2, self.y1 = self.y1, y
        return y
```

看清楚 `self.x1`、`self.x2` 就是 $z^{-1}x$、$z^{-2}x$，`self.y1`、`self.y2` 就是反馈的 $z^{-1}y$、$z^{-2}y$。**你在 z 平面上写下的每一个 $z^{-1}$，到代码里就是一次"移位"。** 长延迟（比如梳状滤波器的 $z^{-D}$，$D$ 上千）就不用一串独立变量了，改用 ring buffer 回看 $D$ 格——但道理一样，$z^{-D}$ = 环形缓冲里往回数 $D$ 个位置。

成本也一目了然：一个 biquad 每样本 5 次乘、4 次加，无论信号多长都是 $O(1)$ per sample。这正是 IIR 的省料之处——用一点反馈（极点）换来极低的计算量，代价是稳定性要自己盯。

### 8.2 定点量化：把极点悄悄推出单位圆的那个真实事故

这是最有"驱动味"、也最能咬人的一节。

在浮点里你把极点设在 $z=0.98$，稳稳的。可一旦你要把滤波器跑在**定点 DSP** 或做 int16 量化（嵌入式、低功耗音频芯片、某些老编解码路径），系数 $a_1,a_2$ 就不能是任意实数了——它们得被量化到有限精度的格子上（比如 Q15 定点，只有 $2^{15}$ 个刻度）。

问题来了：**极点位置是系数 $a_1,a_2$ 的函数，系数一被量化到最近的格子上，极点就跟着挪位。** 当你的极点本来就贴着单位圆（高 Q 的窄带滤波器、低频的陡峭滤波器，极点常在 $|z|=0.999$ 这种地方），系数那一点点量化误差，就足以**把极点从圆内推到圆上或圆外**——于是一个在浮点仿真里完美稳定的滤波器，烧进定点芯片后开始自激、输出爆掉。

```python
# 演示: 一个高 Q 的极点, 量化系数后极点跑出单位圆
import numpy as np
b = [1.0, 0.0, 0.0]
a = np.array([1.0, -1.9800, 0.9801])   # 极点在 |z|≈0.99, 圆内, 稳定
print("量化前极点模:", np.abs(np.roots(a)))   # ~0.99, < 1 稳

# 模拟粗糙定点: 把系数量化到 1/64 的格子(约 6 bit 小数)
q = np.round(a * 64) / 64
print("量化后系数:", q)
print("量化后极点模:", np.abs(np.roots(q)))   # 可能 >= 1, 失稳!
```

一线上的应对，全是围绕"别让极点贴着圆"和"别让量化误差乱跑"：

- **能拆就拆成 biquad 级联**，别用一个高阶直接型（direct form）。高阶直接型的系数对极点位置极其敏感，一点误差就天翻地覆；拆成一堆二阶节，每节的极点对自己系数的敏感度低得多。这是定点 IIR 的头号纪律。
- **留稳定余量**：设计时别把极点顶到 $0.999$，给量化误差留出退路（比如限制最大 Q、或在极点半径上留 buffer）。
- **上线前必查极点**：`np.roots(a)` 出来，`np.abs(...)` 全部 < 1 才敢发版。这跟第 11 篇说的"IIR 设计完必查极点"是同一条军规，只是判据从"左半平面"换成"单位圆内"。

> **关键认知**：极点在单位圆内=稳定，这是**理想连续系数**下的结论。真实工程里系数是有限精度的，量化会挪动极点。**贴着单位圆的极点是定点实现里的定时炸弹**——浮点仿真通过不等于芯片上稳定。这是"数学正确"和"工程能跑"之间最典型的一道坎。

## 九、代码实战：画出极零点图，再听它对应的频率响应

前面所有的话，一段代码就能全串起来。我们画两个系统的极零点图和频响，让你亲眼看到"极点位置 ↔ 频响形状"的对应：

1. 上排：14.1 那个一阶 IIR $y[n]=x[n]+0.9y[n-1]$，唯一的极点在 $z=0.9$；
2. 下排：一个反馈梳状滤波器 $y[n]=x[n]+0.85\,y[n-8]$，8 个极点均匀排在单位圆**内侧**一个圆上。

代码用 `scipy.signal` 的真函数——`tf2zpk`（系数求极零点）、`freqz`（求频响），不用任何伪函数：

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import tf2zpk, freqz

fs = 16000

def plot_pz(ax, b, a, title):
    """z 平面: 单位圆 + 极点(x) + 零点(o)"""
    z, p, k = tf2zpk(b, a)
    theta = np.linspace(0, 2*np.pi, 400)
    ax.plot(np.cos(theta), np.sin(theta), 'k--', alpha=0.5, label="Unit circle")
    if len(z):
        ax.scatter(z.real, z.imag, marker='o', s=90,
                   facecolors='none', edgecolors='b', label="Zeros")
    ax.scatter(p.real, p.imag, marker='x', s=90, c='r', label="Poles")
    ax.set_aspect('equal'); ax.grid(True, alpha=0.3)
    ax.set_xlim(-1.4, 1.4); ax.set_ylim(-1.4, 1.4)
    ax.set_title(title); ax.set_xlabel("Real"); ax.set_ylabel("Imag")
    ax.legend(loc="upper left", fontsize=8)
    print(title, "-> 极点模:", np.round(np.abs(p), 4))

def plot_freq(ax, b, a, title):
    """幅度频响(dB), 横轴 Hz —— 这就是沿单位圆走一圈读到的增益"""
    w, H = freqz(b, a, worN=2048)
    ax.plot(w/np.pi*(fs/2), 20*np.log10(np.abs(H) + 1e-9))
    ax.set_title(title); ax.set_xlabel("Frequency (Hz)")
    ax.set_ylabel("Magnitude (dB)"); ax.grid(True, alpha=0.3)

fig, axes = plt.subplots(2, 2, figsize=(13, 10))

# 上排: 一阶 IIR, 极点 z=0.9
b1, a1 = [1.0], [1.0, -0.9]                 # H(z)=1/(1-0.9 z^-1)
plot_pz(axes[0, 0],  b1, a1, "1st-order IIR: pole at z=0.9")
plot_freq(axes[0, 1], b1, a1, "Freq response: low-shelf boost")

# 下排: 反馈梳状, 8 个极点均匀排在圆内
D, g = 8, 0.85
b2 = np.array([1.0])
a2 = np.zeros(D + 1); a2[0] = 1.0; a2[D] = -g   # H(z)=1/(1-g z^-D)
plot_pz(axes[1, 0],  b2, a2, f"Feedback comb: {D} poles on a circle")
plot_freq(axes[1, 1], b2, a2, f"Freq response: comb teeth (fs/D={fs//D} Hz)")

plt.tight_layout()
plt.savefig("fig_14_1_1.png", dpi=110)
plt.show()
```

![上排：一阶 IIR 的极零点图（极点在 z=0.9、零点在原点）与频响（低频被抬高的搁架状曲线）；下排：反馈梳状滤波器 8 个极点均匀排在单位圆内侧半径约 0.98 处，对应频响长出间距 fs/D=2000 Hz 的一排等间距梳齿尖峰](fig_14_1_1.png)

对着两排图，把前八节的话对一遍：

- **上排（一阶）**：极点孤零零在实轴 $+0.9$，最靠近 $z=1$（0 Hz）那一侧，所以频响在低频被拉高、往高频滑落——一条低频搁架式的提升曲线。极点模 0.9 < 1，在圆内，稳。这就是 14.1 手算的那个系统，图和手算完全对得上。
- **下排（梳状）**：$D=8$ 个极点均匀分布在单位圆**内侧**（半径约 $g^{1/D}\approx0.98$，小于 1，所以稳定）。频响长出一排等间距尖峰——梳齿，间距正好 $f_s/D=2000$ Hz。每个尖峰，就对应单位圆上"最靠近某个极点"的那个频率——**离极点越近增益越大**，14.4 那条读图规则在这里肉眼可见。

把梳状的 `g` 从 0.85 改到 0.98，极点会更贴单位圆、梳齿变得又尖又高（回声拖得更长，也就是混响余音变长）；再改成 `1.02`，极点被推出单位圆，滤波器就不稳定了——这在现实里就是**混响算法自激、嗡嗡失控**。改一个反馈参数，极点如何移动、频响如何变化、系统稳不稳，全在这张图上一目了然。这就是 Z 变换作为导航地图的价值。

## 十、这在音频工程里，到底解决了什么问题

把散落各处的例子收进一张表——它们背后都是同一张 z 平面地图：

| 场景 | 背后就是 Z 变换 / 极点零点 |
|------|--------------------------|
| **数字混响调参** | 反馈量决定极点离单位圆多近，直接对应余音长短与稳定边界（拉太满就发振） |
| **梳状 / 镶边 (flanger)** | 一组均匀极点造出梳齿；延迟 $D$ 随时间变化，梳齿滑动就成了 flanger/chorus |
| **陷波器 (notch)** | 在要消除的频率（如 50 Hz 工频哼声）对应的单位圆位置放一对零点，精准掏空 |
| **参量 EQ / 峰值 / 搁架** | 极点零点成对摆放，控制某频段的提升/衰减量与带宽（第 15 篇亲手设计 biquad） |
| **一极点平滑 / DC 阻断** | 一个极点在 $z\approx1$ 附近做低频提升或直流隔离，就是 14.1 那类系统 |
| **IIR 稳定性校验** | 设计出的 IIR，先看极点是否全在单位圆内，再决定敢不敢上线（定点还要防量化挪动极点） |

> **一句话记住**：数字音频里任何带反馈的处理（混响、IIR EQ、梳状/陷波），它的行为和稳定性都写在极点零点图上。学会读这张图，你调参数时就不再是盲目试错，而是在 z 平面上"搬动"极点和零点。

## 十一、埋一个钩子：地图有了，该动手画滤波器了

现在你手里有了导航地图（Z 变换），也知道：极点拉高、零点压低、频响是沿单位圆走一圈、极点必须待在单位圆内（定点还得留余量）。但真要做一个"能用的均衡器"，还有一堆实操问题没解决：

- FIR（无极点、绝对稳定、但笨重）和 IIR（有极点、省料、但要盯稳定性），这两种性格到底该怎么选？
- 给定一个目标（比如"200 Hz 以下衰减 12 dB"），系数 $a$、$b$ 到底怎么算出来？极点零点该摆哪？
- 怎么用 Python 从零设计低通、高通、峰值滤波器，处理一段真实录音，对比处理前后的频谱和听感？

下一篇（第 15 篇，本模块收官），我们就把前面所有积累——卷积、频谱、STFT、极点零点——全部兑现成一件能跑的东西：**亲手撸一个 EQ**。你今天在 z 平面上练的"摆极点、读频响、查稳定"，到那时会一条条变成真的滤波器系数。

## 本篇小结

- **Z 变换是数字世界的拉普拉斯**：把差分方程变成 z 平面上的极点零点图。三个角度看同一件事——物理上 $z^{-1}$=ring buffer 回看一格；数学上它把递推关系代数化、解出 $H(z)=B(z)/A(z)$；工程上系数直接照抄成 biquad 代码。
- **从差分方程推 $H(z)$**：靠延迟性质 $x[n-1]\to z^{-1}X(z)$，两边做 Z 变换。具体到 $y[n]=x[n]+0.9y[n-1]$，得 $H(z)=1/(1-0.9z^{-1})$，极点 $z=0.9$、冲激响应 $0.9^n$、圆内→稳定，手算与图完全一致。
- **零点**（分子为 0）压制能量，**极点**（分母为 0）放大/共振。FIR 无极点（分母=1）天然稳定；IIR 有极点才可能失控。
- **单位圆 = 所有频率**：DTFT 是 Z 变换取 $z=e^{j\omega}$（单位圆上的切片）。频率响应 = 沿单位圆走一圈、感受被极点拉高、被零点压低。
- **三张平面靠 $z=e^{sT}$ 缝合**：$|z|=e^{\sigma T}$——左半平面($\sigma<0$)卷进单位圆内、虚轴卷成单位圆、右半平面卷到圆外。稳定判据从"极点在左半平面"平移成"极点在单位圆内"，逻辑一模一样。
- **拆比喻**：$z^{-1}$="延迟一格"只在写代码/搭延迟线时够用；一旦要分析（读频响、判稳、设计极零点），必须切回"$z$ 是复变量、$H(z)$ 是复平面上的函数"，否则稳定性、取值、代数化全看不见。
- **收敛域 ROC**：光有 $H(z)$ 分式不够，同一分式配不同 ROC 是不同系统（因果衰减 vs 反因果增长）。因果 ⟺ ROC 在最外极点之外；稳定 ⟺ ROC 含单位圆。对因果系统这两条合体，才等于"极点全在单位圆内"。
- **工程红线**：极点在圆内是理想系数的结论；**定点量化会挪动极点**，贴着单位圆的极点是定时炸弹——拆 biquad 级联、留稳定余量、上线前必查 `np.abs(np.roots(a))<1`。
