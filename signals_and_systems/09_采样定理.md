# 第 9 篇｜采样定理：麦克风如何把连续声波"偷"成一串数字

> 一句话核心直觉：采样，就是给连续的声波**拍连拍照片**。拍得够快，一串照片就能忠实还原运动；拍得太慢，飞快的运动就会被拍成假象——一个真实的高频被"偷"成了一个根本不存在的低频，这就是**混叠 (aliasing)**。

---

## 一、先别看公式，我们看车轮倒转

上一篇我们在频域里聊透了幅度与相位，但留了个根基性的钩子：麦克风是怎么把**连续**的空气振动，变成电脑里**离散**的一串数字的？这一步没做好，前面三篇的频谱分析全是空中楼阁。

先看一个你在电影里一定见过的怪现象：镜头里飞驰的汽车，车轮有时看起来**在倒转**，甚至静止不动。车明明在往前冲，轮子怎么会倒着转？

原因在于摄影机是**一帧一帧拍**的（比如每秒 24 帧）。如果车轮转得太快，在两帧之间轮子转过了大半圈，那么连续的画面看起来就像轮子只往回退了一点点——**快速的真实运动，被稀疏的采样"看"成了一个缓慢的、方向相反的假运动。**

**这就是混叠的完美类比，而且不是类比——它就是同一件事。** 声音采样面临一模一样的问题：

> 麦克风+ADC 不是连续记录声波，而是每隔一个固定的小间隔"看一眼"当前的声压值，记下一个数。每秒看的次数，就是**采样率 $f_s$**（CD 是 44100 次/秒）。如果声音里有个频率太高的成分，在两次采样之间它已经振动了大半个周期，那么这串采样点连起来，看着就像一个**频率低得多的、根本不存在的**波——高频被伪装成了低频。

车轮倒转，是眼睛被采样率骗了；混叠，是频谱被采样率骗了。

---

## 二、采样定理：多快才算"够快"

那到底要每秒看多少眼，才不会被骗？答案就是大名鼎鼎的**奈奎斯特-香农采样定理**，它朴素得可以一句话说完：

> **采样率必须大于信号中最高频率的两倍。**

$$f_s > 2 f_{\max}$$

这里的 $f_s/2$（采样率的一半）有个名字叫**奈奎斯特频率**：**它就是这套系统能忠实记录的最高频率上限。** 采样定理的要求，换个说法就是——信号里的最高频率 $f_{\max}$ 必须**低于**奈奎斯特频率（$f_{\max} < f_s/2$）。超过这条线的频率，一律会被混叠成线以下的假频率，污染你的信号。

**为什么偏偏是"两倍"？** 直觉是这样的：要辨认一次完整的振动（一上一下），你至少得在这次振动里采到两个点——一个抓住"上"，一个抓住"下"。如果一个周期里只采到一个点，你根本分不清它是在上下振动还是干脆没动，更别说算出它的频率了。所以采样率必须至少是信号最高频率的两倍，才能保证每个周期都被"看"到两次以上。

现在你就能秒懂那两个到处出现的数字了：

- **人耳听觉上限约 20 kHz。** 要完整记录人能听到的全部频率，采样率至少得 $2 \times 20 = 40$ kHz。
- **44.1 kHz（CD）**：在 40 kHz 之上留了点余量给滤波器过渡（见下节），加上早期数字录音设备的一些历史原因，定在了 44.1 kHz。
- **48 kHz（专业音视频）**：影视、专业音频行业标准，余量更足，也便于和视频帧率做换算。
- 更高的 **96 / 192 kHz**：用于录音制作阶段，留足处理余量，减少各种加工带来的失真堆积。

> **关键认知**：采样率不是越高越好听（人耳反正听不到 20 kHz 以上），它是一道**工程底线**——保证你想要的频率都在奈奎斯特频率以下，不被混叠污染。

## 三、抗混叠滤波器：采样之前必须先"剪掉"高频

问题来了：现实世界的声音里，含有大量超过 20 kHz 的成分（虽然人耳听不到，但它们真实存在）。如果直接以 44.1 kHz 采样，这些超过 22.05 kHz（奈奎斯特频率）的成分**不会消失，而是会混叠折返**，变成 20 kHz 以下的假频率，堂而皇之地混进你能听到的频段里，制造出原本不存在的杂音。

解决办法简单而强硬：**在采样之前，先用一个低通滤波器把所有超过奈奎斯特频率的成分统统砍掉。** 这个把守在 ADC 大门前的低通滤波器，就叫**抗混叠滤波器 (anti-aliasing filter)**。

- 它必须是**模拟**的、在采样**之前**动手——因为一旦采样完成，混叠已经发生，事后再滤是救不回来的（假频率和真信号已经缠在一起，分不开了）。
- 这也解释了上一节为什么要留"过渡余量"：理想的"一刀切"滤波器不存在，真实滤波器从通过到截止需要一段过渡带。44.1 kHz 相对 40 kHz 多出的那 4 kHz，就是留给滤波器平滑过渡用的。

对应地，播放端（DAC）也有个"重建滤波器"，把离散的采样点重新平滑成连续波形——同样是靠低通滤波把采样引入的高频镜像抹掉。

## 四、代码实战：亲眼制造一次混叠

光说不信。我们造一个频率**高于**奈奎斯特频率的正弦波，用不够快的采样率去采它，看它被"偷"成什么样。

```python
import numpy as np
import matplotlib.pyplot as plt

# 用一个"高分辨率"的时间轴模拟连续的真实声波
fs_true = 44100
t_fine = np.arange(0, 0.01, 1/fs_true)      # 10ms

f_signal = 900                               # 真实信号 900Hz
true_wave = np.sin(2 * np.pi * f_signal * t_fine)

# 用一个太低的采样率去采样它: fs = 1000Hz, 奈奎斯特频率只有 500Hz
# 900Hz 远超 500Hz,必将混叠
fs_low = 1000
t_samp = np.arange(0, 0.01, 1/fs_low)
samples = np.sin(2 * np.pi * f_signal * t_samp)

# 900Hz 被 1000Hz 采样后混叠到: |900 - 1000| = 100Hz
alias_f = abs(f_signal - fs_low)             # = 100Hz
alias_wave = np.sin(2 * np.pi * alias_f * t_fine)

plt.figure(figsize=(10, 5))
plt.plot(t_fine, true_wave, 'b-', alpha=0.4, label=f"True signal {f_signal}Hz")
plt.plot(t_samp, samples, 'ro', markersize=8, label=f"Samples @ {fs_low}Hz")
plt.plot(t_fine, alias_wave, 'g--', label=f"Aliased ghost {alias_f}Hz")
plt.title("Aliasing: a 900Hz tone sampled too slowly becomes a fake 100Hz tone")
plt.xlabel("Time (s)"); plt.ylabel("Amplitude"); plt.legend()
plt.tight_layout()
plt.show()
```

![红点是从蓝色 900 Hz 真波上以 1000 Hz 采下的样本，连起来却完美落在绿色 100 Hz 假波上——高频被采样偷成了低频鬼影](fig_09_1_1.png)

看那张图：**红点（采样点）明明是从蓝色的 900 Hz 波上取下来的，可把它们连起来，却完美地落在了绿色的 100 Hz 假波上。** 电脑拿到这串红点，根本无从知道它们原本来自 900 Hz——它只会认为这是个 100 Hz 的声音。900 Hz 就这样被"偷"成了 100 Hz，一个凭空出现的鬼影。混叠公式也一目了然：$|f_{signal} - f_s| = |900-1000| = 100$ Hz。

再验证一下"够快就没事"：把 `fs_low` 改成 `3000`（奈奎斯特频率 1500 Hz > 900 Hz），红点就会乖乖落回蓝色的真波上，鬼影消失。**这就是采样定理那条 $f_s > 2f_{\max}$ 底线的意义。**

顺带做个能听的混叠——降采样不做抗混叠滤波：

```python
from scipy.io import wavfile
# 造一段扫频从 200Hz 一路升到 8000Hz
fs = 44100
t = np.arange(0, 3, 1/fs)
sweep = np.sin(2*np.pi*(200*t + (8000-200)/(2*3)*t**2))

# 粗暴降采样到 6000Hz(奈奎斯特 3000Hz),且故意不做抗混叠滤波
factor = fs // 6000
bad = sweep[::factor]                          # 直接抽点 -> 制造混叠
wavfile.write("aliased_sweep.wav", 6000, np.int16(bad/np.max(np.abs(bad))*32767))
```

放出来听：扫频升到超过 3000 Hz 后，音高不再继续升高，反而**掉头往下滑**——这就是听得见的混叠，和电影里车轮倒转是同一个鬼。

## 五、这在音频工程里，到底解决了什么问题

| 场景 | 采样定理在其中的角色 |
|------|--------------------|
| **ADC / 麦克风前端** | ADC 前必挂模拟抗混叠低通滤波器，先砍掉奈奎斯特频率以上成分再采样 |
| **44.1k / 48k 的由来** | 人耳上限 ~20kHz，采样率取其两倍再留滤波余量，是工程底线的直接结果 |
| **重采样 (resampling)** | 变采样率时（如 48k→44.1k）必须先低通滤波再抽点，否则引入混叠。所有正经重采样库都内置了这步 |
| **合成器 / 虚拟乐器** | 数字振荡器生成方波、锯齿波含无穷高谐波，超过奈奎斯特的谐波会混叠成刺耳杂音，故需"抗混叠振荡器" |
| **lo-fi / 复古效果** | 故意降低采样率且不做抗混叠，让混叠鬼影和量化噪声成为一种粗糙、复古的音色审美 |

> **一句话记住**：**采样把连续声波变成一串数字，采样率的一半（奈奎斯特频率）是这套系统的频率天花板；越过天花板的频率不会消失，只会伪装成低频溜进来。** 抗混叠滤波器就是那个在门口把关、不让高频溜进来的保安。

## 本篇小结

- **采样 = 给声波拍连拍**：每秒拍 $f_s$ 次，把连续声波记成一串数字。
- **采样定理**：$f_s > 2f_{\max}$。采样率的一半（奈奎斯特频率）是能忠实记录的频率上限。
- **混叠**：超过奈奎斯特频率的成分不会消失，会折返伪装成低频鬼影——和电影里车轮倒转是同一回事。
- **抗混叠滤波器**：采样前用模拟低通砍掉超限高频；事后无法补救，因为混叠已把真假频率缠死。
- **工程意义**：44.1k/48k 的由来、重采样、抗混叠振荡器，乃至故意做混叠的 lo-fi 效果，全由这条定理主宰。
