# 第 7 篇｜傅里叶变换：从时域波形到频谱

> 一句话核心直觉：傅里叶变换是一把**棱镜**。阳光看着是白的，穿过棱镜就摊成红橙黄绿的光带；一段声音看着是杂乱起伏的波形，穿过傅里叶变换就摊成"哪些频率、各有多强"的频谱。

---

## 一、先别看公式，我们看一台频谱仪

上一篇我们把**周期**乐音拆成了一张离散的谐波配方表。但我留了个钩子：真实世界的声音——一句话、一声鼓、一段旋律——都不是无限重复的周期波。对这些活生生的声音，还能不能问"它含哪些频率"？

能。而且你天天都在看这个问题的答案。

打开任何一个音频软件，那个随音乐上下跳动、横轴是频率、纵轴是能量的彩色滚动图（频谱图 / spectrogram），或者调音台上那条 EQ 分析曲线——**它们展示的就是傅里叶变换算出来的结果**。低频段鼓点一响就凸起，人声一来中频段就亮，镲片一敲高频段就炸开。

这台"仪器"到底在干什么？它在回答一个问题：

> 此刻这段随时间起伏的波形，如果要用一堆不同频率的纯正弦波拼出来，**每个频率各需要用多少**？

把每个频率"需要用多少"沿频率轴画出来，就是**频谱 (spectrum)**。傅里叶变换，就是从波形算出这张频谱的数学过程。棱镜分解白光，它分解声音——干的是同一件事。

---

## 二、从配方表到连续频谱：让周期趋于无穷

第 6 篇的傅里叶级数，给周期信号拆出的是**一根根离散的竖线**（只在 $f_0, 2f_0, 3f_0\dots$ 处有值）。为什么是离散的？因为周期 $T$ 限定了：能存在的频率只能是 $1/T$ 的整数倍，竖线间距就是 $f_0 = 1/T$。

现在做一个思想实验。把这个周期 $T$ 慢慢拉长——从 1 秒，到 10 秒，到 100 秒……

- 竖线间距 $f_0 = 1/T$ 越来越小，竖线越来越密；
- 当 $T \to \infty$（信号不再重复，成了一段独一无二、非周期的声音），竖线密到糊成一片，**离散的竖线就连成了一条连续的曲线**。

这就完成了从傅里叶级数到傅里叶变换的跨越：

> **傅里叶级数**处理周期信号，给出**离散**频谱（一根根谐波竖线）；
> **傅里叶变换**处理非周期信号，给出**连续**频谱（一条覆盖所有频率的曲线）。

一句话：**傅里叶变换 = 周期拉到无穷大的傅里叶级数。** 从"这个音色由哪几根谐波组成"升级成了"这段声音在每一个频率上各有多少能量"。

## 三、棱镜的原理：用正弦当"探针"去问

那这条连续频谱到底怎么算出来？原理简单得惊人，而且第 6 篇已经预告过了。

想知道"这段声音里含不含 440 Hz 这个频率"，你只需要做一件事：

**拿一个标准的 440 Hz 纯正弦波当"探针"，让它和这段声音逐点相乘，再把结果全部累加起来。**

为什么这招管用？关键在于正弦波的一个性质：

- 如果声音里**真含** 440 Hz 成分，那么它和 440 Hz 探针"步调一致"，相乘之后正对正、负对负，结果大多为正，累加起来是一个**大数**；
- 如果声音里**不含** 440 Hz，那么它和探针步调时而对齐、时而相反，相乘的正负值在累加时**相互抵消**，结果趋近于 **0**。

于是：**换上不同频率的探针，逐个去问一遍，得到的一串"响应强度"就是频谱。** 探针频率对上了信号里真实存在的频率，就亮（大数）；对不上，就灭（近零）。这就是那把棱镜的内部机制——它不神秘，就是"拿各种频率的尺子去逐一比对"。

现在再看公式，你会发现它就是这句话的直译：

$$X(f) = \int_{-\infty}^{+\infty} x(t)\, e^{-j 2\pi f t}\, dt$$

逐字翻译成人话：

- $x(t)$：待分析的那段声音波形；
- $e^{-j2\pi ft}$：频率为 $f$ 的那根**探针**（用复指数写，是为了一次同时携带 $\cos$ 和 $\sin$ 两个方向，从而顺带算出相位——下一篇的主角）；
- 相乘再 $\int dt$（积分）：就是"逐点相乘再累加"，问一遍"信号里含多少 $f$"；
- $X(f)$：对每个频率 $f$ 问完得到的答案，就是频谱。

那个曾经让人头皮发麻的 $e^{-j2\pi ft}$，本质不过是"频率为 $f$ 的探针"。积分号也不过是"累加"。你已经理解它了。

> **一个必须澄清的点**：$X(f)$ 一般是个**复数**。它的**模长 $|X(f)|$** 表示频率 $f$ 有多强（幅度谱），它的**幅角 $\angle X(f)$** 表示这个频率成分的相位（相位谱）。频谱天生有"两张脸"——这正是第 8 篇要专门讲的、被大多数人忽视的那半张。

## 四、代码实战：亲手把波形送进棱镜

电脑处理的是离散采样，用的是傅里叶变换的离散版本 **DFT**，而它的快速算法叫 **FFT**（Fast Fourier Transform）——现代音频里无处不在的三个字母。我们来做个实验：造一段**混了三个频率**的声音，看 FFT 能不能精准地把它们仨拎出来。

```python
import numpy as np
import matplotlib.pyplot as plt

fs = 8000                      # 采样率 8kHz
dur = 1.0
t = np.arange(int(fs * dur)) / fs

# ---------- 1. 造一段混了 3 个频率的声音 ----------
# 220Hz(强) + 440Hz(中) + 1000Hz(弱)
x = (1.0 * np.sin(2 * np.pi * 220 * t)
     + 0.5 * np.sin(2 * np.pi * 440 * t)
     + 0.2 * np.sin(2 * np.pi * 1000 * t))

# ---------- 2. 送进棱镜: FFT ----------
X = np.fft.rfft(x)                     # 实信号用 rfft, 只保留正频率
freqs = np.fft.rfftfreq(len(x), 1/fs)  # 每个 bin 对应的真实频率(Hz)
mag = np.abs(X) / len(x) * 2           # 取模长并归一化成幅度

# ---------- 3. 画: 时域看不出,频域一目了然 ----------
fig, ax = plt.subplots(2, 1, figsize=(10, 6))
ax[0].plot(t[:400], x[:400])
ax[0].set_title("Time domain: a messy-looking waveform")
ax[0].set_xlabel("Time (s)"); ax[0].set_ylabel("Amplitude")

ax[1].plot(freqs, mag)
ax[1].set_title("Frequency domain (spectrum): three peaks pop out")
ax[1].set_xlabel("Frequency (Hz)"); ax[1].set_ylabel("Magnitude")
ax[1].set_xlim(0, 1500)
plt.tight_layout()
plt.show()
```

![上图时域波形三个正弦叠加已面目全非，下图频谱在 220/440/1000 Hz 处立起三根尖峰，高度正是 1.0/0.5/0.2 的原始配比](fig_07_1_1.png)

对比两张图，冲击力就出来了：**上面那条波形你盯着看半天也数不出里面藏了几个频率**（三个正弦叠在一起，波形已经面目全非）；**可下面的频谱里，220、440、1000 Hz 处赫然立着三根尖峰，高度还恰好是 1.0、0.5、0.2**——正是我们放进去的配比。棱镜把混在一起的光，干净利落地摊开了。

再看真实音频随时间变化的频谱（**语谱图 / spectrogram**），这才是语音工程师每天面对的图：

```python
# ---------- 短时傅里叶变换: 看频谱如何随时间变化 ----------
# 造一段频率随时间上滑的扫频声(chirp): 从 200Hz 滑到 2000Hz
sweep = np.sin(2 * np.pi * (200 * t + (2000 - 200) / (2 * dur) * t**2))

plt.figure(figsize=(10, 4))
plt.specgram(sweep, NFFT=256, Fs=fs, noverlap=128)
plt.title("Spectrogram: a frequency sweep rising over time")
plt.xlabel("Time (s)"); plt.ylabel("Frequency (Hz)")
plt.colorbar(label="Energy (dB)")
plt.tight_layout()
plt.show()
```

![扫频声的语谱图：一条从低频往高频爬升的亮线，是把声音切成小片、逐片做 FFT 再沿时间轴拼起来的结果](fig_07_2_1.png)

你会看到一条从低往高爬升的亮线——**这就是把一整段声音切成许多小片、对每片各做一次 FFT、再沿时间拼起来**得到的图（叫短时傅里叶变换 STFT）。语音里的元音共振峰、音乐里的旋律走向，在这张图上都看得一清二楚。你手机里的语音识别、变声、降噪，第一步几乎都是先把声音变成这张图。

## 五、这在音频工程里，到底解决了什么问题

| 技术 | 背后就是傅里叶变换 |
|------|------------------|
| **频谱仪 / EQ 分析曲线** | 实时对信号做 FFT，把幅度谱画出来给你看 |
| **均衡器 (EQ)** | 到频域里精准地抬高或压低某些频率成分，再变回时域 |
| **降噪 / 语音增强** | 在频谱上找出噪声所在的频率区块，压制它，保留人声频段 |
| **音频压缩 (MP3/AAC)** | 变到频域后，扔掉人耳听不到的频率成分来省码率（心理声学) |
| **语音识别前端** | 先做 STFT 得到语谱图，再提取 MFCC 等特征喂给模型 |
| **快速卷积** | 就是第 5 篇留的钩子——见下一节 |

> **一句话记住**：**时域是"声音随时间怎么变"，频域是"声音由哪些频率组成"，傅里叶变换就是这两个世界之间的双向门。** 很多在时域里束手无策的问题（比如"去掉 60 Hz 交流声但保留人声"），换到频域就变得轻而易举。

### 顺便，兑现第 5 篇的承诺

第 5 篇结尾我埋了个钩子：时域里昂贵的卷积，到频域会变成廉价的乘法：

$$x(t) * h(t) \quad\xrightarrow{\text{傅里叶变换}}\quad X(f)\cdot H(f)$$

现在你能看懂它为什么成立的直觉了：卷积是"每个频率成分各自被系统如何缩放和延迟"的叠加结果，而一旦到了频域——每个频率被单独拎出来——系统对它的作用就退化成"乘一个数"。于是几百亿次乘加的卷积，变成了"FFT → 逐点相乘 → 逆 FFT"。这就是混响插件能在笔记本上实时跑的秘密：**快速卷积 (fast convolution)**。

## 六、埋一个钩子：频谱有两张脸，我们只看了一张

这一篇我们画频谱时，用的全是 `np.abs(X)`——**只取了模长（幅度）**。这是绝大多数教程、绝大多数人默认的做法：频谱嘛，不就是"每个频率多强"？

但你还记得吗，$X(f)$ 是个**复数**。取模长，我们只用了它一半的信息。另一半——**相位 $\angle X(f)$**——被我们悄悄扔掉了。

那扔掉的这一半重要吗？教材往往一笔带过，好像它只是个无关紧要的附属品。

**大错特错。** 下一篇我会用一个让你后背发凉的实验证明：**如果把两段不同音乐的幅度谱和相位谱交叉互换，你听到的，是提供了"相位"的那一段。** 相位——那个被忽视的、决定"每个频率何时到达"的量——才是决定声音瞬态、空间感、乃至"这到底是谁的声音"的关键。

推开门的另一半，我们下一篇见。

## 本篇小结

- **傅里叶变换是棱镜**：把随时间起伏的波形，分解成"哪些频率、各有多强"的频谱。
- **它是周期趋于无穷的傅里叶级数**：离散的谐波竖线连成连续的频谱曲线，处理对象从周期乐音扩展到任意声音。
- **机制**：用不同频率的正弦当探针，逐点相乘再累加——对上了就亮，对不上就抵消成零。
- **FFT / STFT**：电脑用 FFT 快速算 DFT；把声音切片逐段做 FFT 再拼起来，就是语音工程师天天看的语谱图。
- **工程意义**：EQ、降噪、音频压缩、语音识别前端、快速卷积，全都建立在这道时域↔频域的门上。
- **下一步**：频谱是复数，有幅度和相位两张脸——我们只看了幅度，被忽视的相位其实更关键。
