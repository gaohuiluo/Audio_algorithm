# 《符号与约定表》 v1.0

> 全系列 18 篇统一使用。后续每篇沿用，不再重复定义、不允许冲突。

| 类别 | 符号 | 含义 | 备注 |
|------|------|------|------|
| **采样/时间** | `fs` | 采样率 (Hz) | 示例常用 48000 / 16000 |
| | `Ts` | 采样周期 (s) | `Ts = 1/fs` |
| | `t` | 连续时间 | 单位 s |
| | `n` | 离散样本索引 | 整数 |
| | `x(t)` / `x[n]` | 连续 / 离散信号 | 方括号=离散 |
| **频率** | `f` | 物理频率 (Hz) | |
| | `Ω` | 模拟角频率 | `Ω = 2πf` (rad/s) |
| | `ω` | 数字角频率 | `ω = 2πf/fs` (rad/sample)，范围 (−π, π] |
| | `fN` | 奈奎斯特频率 | `fN = fs/2` |
| **变换** | `X(jΩ)` | 连续频谱 (CTFT) | |
| | `X(e^{jω})` | 离散时间傅里叶变换 (DTFT) | 频率连续 |
| | `X[k]` | 离散傅里叶变换 (DFT) | `k = 0…N−1` |
| | `N` | DFT / 帧点数 | |
| | `Δf` | 频率分辨率 | `Δf = fs/N` |
| **系统** | `h[n]` | 冲激响应 | |
| | `H(·)` | 频率响应 / 传递函数 | |
| | `*` | 卷积运算 | |
| **量化/指标** | `B` | 量化比特数 | |
| | `Δ` | 量化步长 | |
| | `SNR / SINAD / THD+N` | 信噪比类指标 | |
| | `dBFS` / `dBSPL` | 满量程 / 声压级 | 二者含义不同 |
| **STFT/帧**（06 起） | `L / R / w[n] / ℓ` | 帧长 / 帧移 / 窗 / 帧索引 | |
| **自适应**（09 起） | `w / μ / e[n] / d[n] / λ` | 权重 / 步长 / 误差 / 期望 / 遗忘因子 | |

**代码约定**：Python（numpy / scipy / matplotlib）为主，关键算法给 C 落地思路；变量命名与上表一致。
