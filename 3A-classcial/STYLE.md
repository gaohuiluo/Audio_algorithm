## (C) 全局符号表

严格采用以下约定，全系列不得混用：

| 符号 | 含义 | 备注 |
|---|---|---|
| `x[n]` | 离散时域信号，`n` 为采样点索引 | 方括号强调离散 |
| `x⃗` | 向量（列向量） | 抽头系数、观测帧等 |
| `X` | 矩阵 | 协方差 `R`、导向矩阵等大写 |
| `f_s` | 采样率 (Hz) | 全系列默认 16000 |
| `N` | 帧长（样本数） | STFT 窗长 |
| `H` | 帧移 (hop size) | 常取 `N/2` |
| `X(t,f)` | STFT 复数谱，`t` 帧索引、`f` 频点索引 | 时频域主变量 |
| `|X(t,f)|` | 幅度谱 | |
| `∠X(t,f)` | 相位谱 | 降噪常沿用带噪相位 |
| `M(t,f)` | 理想掩蔽 (mask)，取值 `[0,1]` | 维纳增益/掩码 |
| `L(·)` | 损失函数 | |

**派生约定（各篇沿用，不再重复定义）：**

| 符号 | 含义 |
|---|---|
| `d[n]` | 期望信号 (desired) / 麦克风采集信号 |
| `e[n]` | 误差信号 `e[n] = d[n] - ŷ[n]` |
| `w⃗` | 自适应滤波器抽头，长度 `L` |

| `ξ_prior(t,f)` | 先验 SNR (a priori) |
| `γ_post(t,f)` | 后验 SNR (a posteriori) |
| `λ_d(t,f)` | 噪声功率谱估计 |
| `R` | 空间协方差矩阵（阵列篇） |
| `θ` | 声源到达角 (DOA) |

## (D) 风格红线（硬性）

1. **每个公式后必须跟“人话翻译”** —— 用一句大白话说清这个式子在干嘛。
2. **禁用词**：`显然` / `易得` / `不难看出` / `众所周知` / `trivially` / `obviously`。
3. **关键结论**用引用块：`> ⭐ **结论**：...`
4. **面试高频题**用：`> 🔥 **面试追问**：...`
5. **代码**用 NumPy，变量带 shape 注释：`feat  # [B, T, F]`；且必须真实可跑。
6. **行文用工程师口吻**，多用比喻：EQ / 滤水器 / 镜子 / 调音师 / 回声墙 等。
7. 图表放 `figures/`，正文用相对路径引用，图注说清横纵轴与结论。
