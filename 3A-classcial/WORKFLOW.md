# WORKFLOW.md — 本仓库的博客生产手册（新会话请先读我）

> 如果你是被指派来生产新主题博客的 AI：**先完整读本文件**，再读 `STYLE.md`。
> 本仓库已用这套流程产出「经典 3A 算法」8 篇（见 `PLAN.md`），请对新主题**原样复现**。

---

## 一、核心原则：为什么这么做

痛点：在一条会话里连续写多篇深度长文，上下文越堆越满，**后几篇质量会下滑**（推导变糙、符号漂移、比喻偷懒、配图省略）。

解法：**不要一篇接一篇地在主会话里写**。而是——
- 每篇派一个**独立子代理**（Agent 工具，general-purpose），它拥有**全新干净上下文**；
- 子代理只带：本手册要点 + `STYLE.md` + 该篇规格 + 邻篇衔接点；
- 这样第 N 篇和第 1 篇拿到**同样的注意力预算**，不是一条越写越累的链条。

## 二、施工步骤（严格按序）

1. **规划**：与用户确认主题范围后，更新/新建 `PLAN.md`：
   - (A) 每篇标题 + 2~3 句核心问题陈述；
   - (B) 各篇依赖关系的 Mermaid 知识图谱；
   - (C)/(D) 复用 `STYLE.md`（符号表 + 风格红线），如新主题需要新符号，**追加到 `STYLE.md` 表格**。
2. **建任务**：用 TaskCreate 为每篇建一条任务，便于跟踪。
3. **并行派活**：用 Agent 工具**一次性并行**派出全部篇目（每篇一个子代理）。派活提示词见第三节模板。
4. **等待 + 记账**：子代理跑完会发完成通知；逐篇 TaskUpdate 标完成，并更新 `PLAN.md` 进度表。
5. **总校验**：全部完成后跑 `python scripts/gate.py all`，确认 8×✅。
6. **汇报**：给用户一张表（篇 / 主题 / 图数 / 关键实测数据）。**不要**把正文全文贴进主会话。

## 三、派活提示词模板（复制改写）

> 给每个子代理的 prompt 用这个骨架，把 `<...>` 换成该篇内容：

```
你要独立撰写一篇技术博客正文并交付可跑代码。项目根目录：E:\Android\3A-classcial
第一步先读（必须严格遵守）：
- <根目录>\STYLE.md（符号表 + 风格红线 + 强制结构 + 自评清单）
- <根目录>\PLAN.md（找到"<系列 N>"的标题与核心问题）
- <根目录>\WORKFLOW.md（了解交付标准）

你的任务是撰写【<标题>】。前置来自<邻篇>，开头一句话衔接。
内容要点（公式后必须跟"人话翻译"）：<把该篇的痛点故事/直觉比喻/数学推导/代码实战要点逐条列清>

交付物：
1. 正文写入 posts/series-<N>.md，遵循 STYLE.md 的 7 章节强制结构
   （标题含关键词：TL;DR、工程痛点、直觉、数学推导、代码实战、工程踩坑、小结），
   关键结论用 > ⭐，面试题用 > 🔥。
2. 代码写入 code/series-<N>.py，必须实际可跑；用 matplotlib 出图存 figures/（前缀 s<N>_），
   脚本开头 `import matplotlib; matplotlib.use("Agg")`，图内文字用英文（避免中文字体报错），
   正文用中文；代码变量带 shape 注释；正文用相对路径 ../figures/xxx.png 引用并配图注。
3. 运行 `python code/series-<N>.py` 确认无报错。
4. 运行 `python scripts/gate.py <N>` 直到输出"✅ 系列 <N> 全绿"，不过则修改后重跑。
完成后一句话回报：系列<N>已过审 + 生成了哪几张图。不要回报正文全文。
```

## 四、质量门禁 `scripts/gate.py`

- 已存在、通用。校验：违禁词（显然/易得/不难看出…）、7 章节结构、⭐/🔥 标记、**实跑配套代码**、
  **博客自包含**（正文不得有 `../code/` 死链，且须内嵌完整代码块）。
- 若新主题的章节关键词或违禁词需调整，改 `scripts/gate.py` 顶部的 `BANNED` / `REQUIRED_SECTIONS`。

## 四之二、博客自包含：代码必须内嵌进正文

**要求**：文章要能整篇上传到博客网站，读者无需翻独立文件——所以**完整可跑代码必须内嵌在正文里**，
正文里**不能出现** `../code/xxx.py` 这类相对链接（上传后是死链）。

**做法（自动化，勿手改 8 遍）**：
- `.py` 文件仍保留在 `code/`，作为 `gate.py` 的"可测试源"（继续被实跑验证）；
- 每篇写完后运行 `python scripts/embed_code.py`，它会：
  1. 把正文里指向 `../code/series-N.py` 的外链句改写为"文末《完整可跑代码》"；
  2. 在「## 5. 工程踩坑」之前插入 `### 完整可跑代码` 小节，内嵌整份 `.py`
     （带 `AUTO-EMBED` 标记，幂等，可反复重跑同步）。
- 派活给子代理时，在交付物里加一句：**"正文的讲解片段照旧，但完整代码由 `scripts/embed_code.py` 内嵌；
  正文不要出现 `../code/` 外链。"** 或子代理写完后由主会话统一跑 `embed_code.py`。

## 五、环境备忘

- Python 3.12，已装 numpy / scipy / matplotlib。
- Windows 控制台是 GBK：任何要打印 emoji 的脚本，开头加
  `sys.stdout.reconfigure(encoding="utf-8")`（`gate.py` 已处理）。
- matplotlib 图内文字**一律英文**，避免中文字体缺失报错；正文 markdown 用中文。
