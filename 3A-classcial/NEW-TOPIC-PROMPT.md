# 开新主题 · 复制这段话给新会话的 AI 即可

> 用法：开一个新会话，把下面 ``` 代码块里的整段话复制发给我，
> 把 **【方括号】** 里的内容换成你的新主题即可。其余不用改。

```
项目根目录 E:\Android\3A-classcial 是一个技术博客生产仓库。
请先读 WORKFLOW.md（生产手册）和 STYLE.md（符号表+风格红线），
严格按 WORKFLOW.md 的流程为一个【新主题】生产系列博客。

新主题是：【在这里写主题，例如"音频编解码原理与实战"】
我希望覆盖的要点/大纲：【逐条列出你想讲的子题；不确定就写"你先提一版大纲我确认"】
每篇定位：深度长文 + 多图，公式讲透、配可跑 NumPy 代码和真实配图。

请按 WORKFLOW.md 执行：
1) 先更新 PLAN.md（新主题的标题清单+核心问题+知识图谱），并把新主题需要的新符号追加进 STYLE.md；
2) 先把规划书给我确认，我说"开始"后，再用并行子代理逐篇撰写；
3) 每篇必须过 scripts/gate.py 门禁（真跑代码+扫违禁词），全绿才算完成；
4) 全部完成后给我一张汇总表，不要把正文全文贴进对话。
```

## 三种组织方式，任选其一

新主题可能和 3A 是不同系列，建议这样放：

- **方式 A（推荐·同仓库分子目录）**：让新会话在 `E:\Android\3A-classcial\topics\<新主题名>\` 下建 posts/code/figures，共用同一套 STYLE.md / gate.py。好处：一套工作流管所有主题。
  → 在上面提示词末尾加一句：「本主题的产出请放在 topics\<主题名>\ 子目录下」。
- **方式 B（各主题独立仓库）**：新建一个空目录当根目录，把本仓库的 `WORKFLOW.md`/`STYLE.md`/`scripts/gate.py` 复制过去，再发上面的提示词（改掉根目录路径）。
- **方式 C（就近混在一起）**：不建子目录，直接继续用 posts/code/figures。主题少时最简单，主题多会乱，不推荐。

> 拿不准就用方式 A。你只要在提示词里说清主题，我会自己按手册把目录、规划、门禁都张罗好。
