## 1. 五条硬约束（继承前系列，一字不改地执行）

### 1.1 直觉先行，数学兜底
每个概念**先给物理/工程画面，再上公式**。公式只保留最核心那一个，出现时**必须逐项翻译成人话**。绝不先甩推导。
> 例：讲 CTC 先带读者"音频 100 帧、答案只有 5 个字，网络每帧都吐一个符号，多出来的用空白符占位，再把连续重复和空白合并"，等直觉建立了，那个对所有对齐路径求和的公式才顺眼。

### 1.2 所有例子锚定语音
一律用识别、合成、唤醒、声纹、降噪、双讲、混响举例。张量每一维都要落到真实含义（帧、频点、音素、说话人）。
**禁用图像分类猫狗、CIFAR、鸢尾花、房价预测、机器翻译英法句子这类通用 ML 教材例子**——注意力也用"语音帧之间互相查询"来讲，不用 NLP 的"词"。

### 1.3 比喻必须有解释力，拒绝装饰性换名
只保留能揭示机制的比喻：CTC 空白符=对齐用的占位符、RNN-T 的"吐字 vs 前进一帧"=打字时按字母键还是按空格键、时长预测器=给每个音素分配几帧画布、声码器=把梅尔画布照着念成波形、说话人嵌入=把一个人的声音压成一个指纹向量、统计池化=把一段话的均值和方差当成这个人的签名、量化=把连续旋钮换成有级档位、蒸馏=让小网络模仿大网络的"软答案"而不只背标准答案。坚决去掉只换花哨说法、不推进理解的修辞。

### 1.4 代码把公式变成可运行
用 PyTorch + NumPy 把概念跑出来，能直接运行、注释讲清每步。**本系列一律"记事内可运行片段"，不生成独立脚本、不产出 PNG/WAV 文件。** 张量操作后**务必打印/标注 shape**。模型级实现给"最小可跑版"（能 forward、shape 对得上、核心机制在），不追求复现论文全部工程细节。结构图用 ASCII 或文字描述数据流，不插入图片文件。

### 1.5 讲"为什么需要"，落到工程
重点是"工程中遇到什么问题、为什么要这个模型/技巧"。凡有条件补一线视角：实时因果性红线（不能看未来帧）、端侧算力/显存/功耗预算（尤其 KWS 常开）、流式推理的状态缓存、量化对定点/复数运算的影响、数据合成与增广策略、客观指标与主观听感的背离、注册/打分阈值怎么定。

```
# 第 N 篇｜模型名/主题：一句话副标题

## 这在工程里解决什么问题          ← 表格/bullet，落到真实任务
## 埋一个钩子                      ← 一两句抛出下一篇要解决的问题
## 本篇小结                        ← bullet 收尾：概念 / 工程意义 / 下一步
```

排版习惯：
- 核心公式用 `$$...$$`，行内用 `$...$`。
- "关键认知"用 `>` 引用块高亮。
- 工程对照、维度含义、方案选型、指标对比常用**表格**。
- 代码块给完整可运行片段，带中文注释，张量操作后标注 shape。
- **每篇目标 ~500-650 行**（模型级内容复杂，推导与代码都要给足）。
- 章节用 一、二、三…；**不要分数标题**（如 二.5），要么升级成独立章，要么用 `### 2.1`。

维度顺序约定（继承前系列，务必贯彻）：
- 波形：`[B, T]` 或 `[B, C, T]`
- 语谱图（实数幅度）：`[B, C, F, T]`（批次、通道、频率、帧）
- 复数谱：`[B, F, T]`（complex64）或实虚拆开 `[B, 2, F, T]`
- RNN 输入：`[B, T, Feature]`（batch_first=True）
- 注意力/编码器序列：`[B, T, D]`（批次、**帧数**、模型维度）——**T 是语音帧数，别用 NLP 的"词数"**
- ASR 输出 logits：`[B, T, V]`（V=词表大小，含空白符）
- 说话人嵌入：`[B, D]`（一句话压成一个向量）

## 4. 六篇总脉络与"钩子接续点"（连续性命脉）

开篇 README 承接 3A/基础系列。一条主线：
**音频→文字(ASR) → 文字→音频(TTS) → 只等一个词·常开(KWS) → 认谁在说(声纹) → 认人前先洗噪(增强) → 从训练到端侧落地(工程)。**

|---|---|---|---|---|
| 00 | `README.md` | 补齐"识别·合成·认人"一侧，收束到部署 | 承接 3A"前端增强只洗声音，没碰识别/合成" | 从最经典的"音频→文字"对齐难题起步 |

| 02 | `02_TTS语音合成.md` | 两段式：声学模型先画梅尔，声码器再读成波形；非自回归+时长预测器 | 承接 01"音频→字"，反向走"字→音频" | 识别/合成都要先听到关键词；端侧常开、极省电怎么做？→ KWS |

## 6. 语气与禁忌

- 第二人称"你"，像老工程师带新人，坦诚讲"当年我卡在哪"。
- 允许口语（"这玩意""折磨我的那个符号"），但技术必须准确。
- 禁忌：不堆公式推导、不罗列 API、不用通用 ML 教材例子、不用 NLP 词讲注意力、不生成 PNG/WAV 独立产物、不写没有解释力的花哨比喻。
- 每出现一个公式，紧跟"逐字翻译成人话"。
- 每段张量操作，紧跟 shape 说明。
- 论文数字/指标只作示意，不编造具体 SOTA 分数；写"量级/相对关系"而非杜撰精确值。
- 代码必须用真实 API（`torch.nn.CTCLoss`、`F.scaled_dot_product_attention` 等），**不发明不存在的函数**。
