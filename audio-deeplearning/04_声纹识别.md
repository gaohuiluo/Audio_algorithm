# 第 4 篇｜声纹识别：把一个人的声音压成一个指纹向量

> 一句话核心直觉：声纹识别不关心你说了什么，只关心你是谁。它的全部任务是把一段**任意长度、任意内容**的语音，压成一个**固定维度**的向量——这个向量就是你的"声音指纹"。同一个人不同时间、说不同话，指纹要尽量靠在一起；不同人的指纹要尽量离得远。于是整条技术线就围绕三件事：**怎么把变长语音池化成定长指纹**（统计池化）、**怎么训练才能让同人聚拢异人分开**（AAM-Softmax 间隔损失）、**拿到两个指纹怎么判是不是同一个人**（余弦打分 + EER 定阈值）。看懂这三件事，就看懂了 ECAPA-TDNN 这类主力声纹模型。

---

## 一、先把教材那套扔一边

上一篇 KWS 回答"说了什么词"，这一篇回答一个正交的问题——"**是谁在说**"。自定义唤醒要认主人、手机解锁要认机主、门禁要核身份、会议纪要要分清谁发言，靠的都是声纹。

先把两类任务分清楚，面试常考：

- **声纹确认**（verification，1:1）：你声称你是机主，系统比对"这段话"和"机主注册的声纹"是不是同一个人，输出是/否。手机语音解锁就是这个。
- **声纹辨认**（identification，1:N）：一段话，在 N 个已注册的人里找出最像的那个。会议分离、嫌疑人比对是这个。

两者底层是同一套：把语音变成指纹向量，再比向量距离。区别只在"比一个"还是"比一堆"。

传统声纹是 GMM-UBM、i-vector 那套（信号处理 + 因子分析），现在工业界主力是深度嵌入——**x-vector** 开的路，**ECAPA-TDNN** 把它做到当前主力水准。这一篇就拆 ECAPA-TDNN，但真正要你记住的不是它的网络图，而是贯穿始终的那三件事。

> **关键认知**：声纹和识别/唤醒最大的不同在于**输出形态**。ASR 输出变长文本、KWS 输出一个是非，而声纹要输出一个**固定维度的向量**（比如 192 维），且这个向量的"远近"要有意义——训练目标不是"分类对不对"，而是"同人近、异人远"的几何结构。这决定了它的池化方式和损失函数都和前几篇不一样。

---

## 二、第一件事：怎么把变长语音压成定长指纹

### 2.1 问题所在

一段语音是帧级特征 `[B, T, F]`——T 帧随内容长短变化（说一个字和说一句话 T 差很多）。但指纹必须是**固定维度** `[B, D]`，不管你说多长。中间必须有一步把"变长的时间维 T"**抹掉**，压成定长。这一步叫**池化**，是声纹模型的命门。

### 2.2 最朴素的：平均池化，和它的问题

最简单的办法：帧级特征沿时间维求平均，`[B,T,F]` → `[B,F]`。这叫平均池化。它能用，但丢了太多信息——它只保留了"平均长什么样"，却没保留"这段话里特征的**波动情况**"。而一个人的声音特性，很大程度藏在波动里。

### 2.3 统计池化：均值 + 标准差

x-vector 的关键一招是**统计池化**：不止求均值 $\mu$，还求标准差 $\sigma$，把两者拼起来：

$$ \mu = \frac{1}{T}\sum_{t=1}^{T} h_t, \qquad \sigma = \sqrt{\frac{1}{T}\sum_{t=1}^{T}(h_t-\mu)^2} $$

$$ \text{pooled} = [\mu \,;\, \sigma] $$

逐项翻译：$h_t$ 是第 $t$ 帧的特征向量，$\mu$ 是所有帧的平均（这个人声音的"中心长相"），$\sigma$ 是所有帧的标准差（这个人声音的"抖动幅度"）。把两个 F 维向量拼成一个 2F 维向量——时间维 T 没了，变成定长。

> **关键认知**：均值回答"你的声音平均长什么样"，标准差回答"你的声音是平的还是起伏大的"。两样合起来才构成一个人的签名——有人声音平稳、有人抑扬顿挫，这个差别全在 $\sigma$ 里。统计池化就是"把一段话浓缩成均值+方差这个签名"的字面实现。

### 2.4 注意力统计池化：不是每帧都值得平均

ECAPA-TDNN 更进一步：不是每一帧都同等重要——静音帧、噪声帧对"你是谁"没贡献，不该和清晰的浊音帧等权平均。于是给每帧学一个**注意力权重** $w_t$，做**加权**的统计池化：

$$ \tilde\mu = \sum_t w_t h_t, \qquad \tilde\sigma = \sqrt{\sum_t w_t (h_t-\tilde\mu)^2} $$

$w_t$ 由一个小网络从 $h_t$ 算出、经 softmax 归一（$\sum_t w_t=1$）。逐项翻译：让网络自己学"哪些帧更能代表这个人"，给它们更大权重，静音/噪声帧权重压低。这就是上一篇和 3A 讲的注意力的又一次复用——这次是"每帧对最终指纹贡献多少"的查询。

---

## 三、ECAPA-TDNN 的骨干：在池化之前把帧级特征做厚

统计池化负责"压成定长"，但压之前的帧级特征得够好。ECAPA-TDNN（Emphasized Channel Attention, Propagation and Aggregation TDNN）在骨干上做了三件实事，名字里都写着：

- **TDNN（时延神经网络）打底**：本质就是一维膨胀卷积，沿时间抽取不同时间跨度的特征——和我们熟的 Conv1d 一回事，膨胀率拉大来看更长的上下文。
- **SE-Res2Block（Channel attention）**：Res2 把一个卷积块内部再分成多个小尺度分支（多尺度感受野，和 HiFi-GAN 的 MRF 异曲同工），SE（Squeeze-Excitation）给每个通道学一个重要性权重——"强调"有用的频道。这就是名字里的 Emphasized Channel Attention。
- **多层特征聚合（Propagation and Aggregation）**：把浅层到深层的特征都汇集到池化前（而不是只用最后一层）——浅层带精细纹理、深层带抽象身份信息，一起喂给池化。

你不用背这张图。记住一句：**骨干的全部目的，是在池化前把每一帧的特征做得既多尺度、又分清通道主次、还融合深浅层**，这样统计池化压出来的指纹才信息量足。

## 四、第二件事：怎么训练才能同人聚拢、异人分开

### 4.1 普通 Softmax 不够

最直接的训法：把它当分类——训练集有几千个说话人，就是几千类，用普通交叉熵分类。能学出能分类的特征，但有个问题：**普通 Softmax 只要求"分对类"，不要求"类内紧、类间远"**。它学出的特征可能勉强分开，但同一个人的指纹散得很开、不同人的边界贴得很近。而声纹推理时要比的是**余弦距离**（测试的人根本不在训练的那几千类里），所以我们真正要的是**嵌入向量在角度上同人聚拢、异人张开**。

### 4.2 AAM-Softmax：在角度上硬塞一个间隔

ECAPA-TDNN 用的是 **AAM-Softmax（加性角间隔 Softmax，又叫 ArcFace）**。它的做法：先把特征向量和分类权重都**归一化到单位长度**，于是分类打分就等于两者夹角的余弦 $\cos\theta$。然后在**正确类**的角度上**硬加一个间隔 $m$**：

$$ L = -\log \frac{e^{s\cdot\cos(\theta_{y}+m)}}{e^{s\cdot\cos(\theta_{y}+m)} + \sum_{j\neq y} e^{s\cdot\cos\theta_{j}}} $$

逐项翻译：$\theta_y$ 是特征和"正确说话人"权重向量的夹角，$\theta_j$ 是和其他人的夹角；$s$ 是缩放系数（把余弦放大，让 softmax 够陡）；关键是那个 $+m$——**它在训练时人为地把正确类的角度加大 $m$ 再算 loss**，相当于要求"特征不仅要离正确类最近，还得近出一个安全间隔 $m$ 才算过关"。

> **关键认知**：那个 $+m$ 是整个声纹训练的灵魂。它逼着网络把同一个人的特征往类中心**挤得更紧**（因为留了间隔的余量才能满足损失），把不同人**推得更开**。推理时比余弦距离，正好吃这个几何结构的红利。普通 Softmax 没这个间隔，学出的指纹就"松"。这和人脸识别用 ArcFace 是同一套道理——都是要可比对的嵌入，不是要分类器。

## 五、第三件事：拿到两个指纹，怎么判是不是同一人

### 5.1 注册与打分

- **注册**（enrollment）：让目标人说几句话，各自过模型得到指纹，取平均当作这个人的"注册模板"。
- **打分**：测试语音过模型得指纹，和注册模板算**余弦相似度** $\cos(\mathbf{e}_1, \mathbf{e}_2) \in [-1,1]$，越接近 1 越像同一人。
- **判决**：相似度超过阈值 $\tau$ 判"同一人"，否则"不同人"。

### 5.2 EER：声纹的核心指标

和 KWS 一样，这里也有两类此消彼长的错误：

- **错误接受**（FAR）：不是本人，却判成了本人（安全隐患，别人能解锁你手机）。
- **错误拒绝**（FRR）：是本人，却判成了别人（体验差，自己解不开）。

扫过所有阈值 $\tau$，当 **FAR == FRR** 的那一点，叫**等错误率 EER**（equal error rate）——这是声纹系统最常用的单一指标，EER 越低系统越好。为什么用这个点？因为它给了一个和阈值无关的、可横向比较的数字。但真正部署时，**阈值不一定定在 EER 点**：手机解锁更怕"别人能解开"（FAR 要极低），就把阈值调高，宁可自己偶尔要多说一遍。

> **关键认知**：EER 是**评测**用的、与阈值无关的比较指标；**部署阈值**则按场景的安全偏好单独定——高安全场景（支付、门禁）把 FAR 压到极低，牺牲一点 FRR。这和 KWS 先钉死误唤醒上限是同一个工程哲学：先定死那条最伤的红线，再优化另一头。

## 六、代码实战：注意力统计池化 + AAM-Softmax + 余弦打分

CPU 可跑。串起声纹的三件事：池化成定长、间隔损失训练、余弦打分。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)
B, T, Fdim, D = 4, 120, 64, 192     # 批4, 120帧, 帧特征64维, 指纹192维

class AttentiveStatsPool(nn.Module):
    """注意力统计池化：加权均值 + 加权标准差，把 [B,T,F] 压成 [B,2F]。"""
    def __init__(self, f):
        super().__init__()
        self.attn = nn.Sequential(nn.Linear(f, f), nn.Tanh(), nn.Linear(f, 1))
    def forward(self, h):                       # h: [B, T, F]
        w = self.attn(h)                        # [B, T, 1]  每帧一个打分
        w = torch.softmax(w, dim=1)             # 沿时间归一, Σ_t w = 1
        mu = (w * h).sum(dim=1)                 # 加权均值 [B, F]
        var = (w * (h - mu.unsqueeze(1))**2).sum(dim=1)   # 加权方差 [B, F]
        sigma = torch.sqrt(var.clamp(min=1e-8))           # 加权标准差 [B, F]
        return torch.cat([mu, sigma], dim=-1)   # [B, 2F]

class SpeakerNet(nn.Module):
    """极简声纹网：Conv 帧级编码 → 注意力统计池化 → 投到 192 维指纹。"""
    def __init__(self, f_in, f_mid, d):
        super().__init__()
        self.enc = nn.Sequential(
            nn.Conv1d(f_in, f_mid, 5, padding=2), nn.ReLU(),
            nn.Conv1d(f_mid, f_mid, 3, dilation=2, padding=2), nn.ReLU(),   # 膨胀卷积看更长上下文
        )
        self.pool = AttentiveStatsPool(f_mid)
        self.embed = nn.Linear(2 * f_mid, d)
    def forward(self, x):                       # x: [B, T, F_in]
        h = x.transpose(1, 2)                   # -> [B, F_in, T]
        h = self.enc(h).transpose(1, 2)         # -> [B, T, f_mid]
        pooled = self.pool(h)                   # -> [B, 2*f_mid]
        return self.embed(pooled)               # -> [B, D]  指纹

net = SpeakerNet(Fdim, 128, D)
feats = torch.randn(B, T, Fdim)                 # 假帧级特征
emb = net(feats)
print("feats:", feats.shape)                    # torch.Size([4, 120, 64])
print("embed:", emb.shape)                      # torch.Size([4, 192])  变长T被抹掉
```

关键看 `pool`：`[4,120,64]` 里那个 120（帧数 T）在池化后彻底消失，变成固定的 `[4,192]`——不管输入多少帧，指纹永远 192 维。这就是第二节说的"抹掉时间维"。

下面是 AAM-Softmax 训练头和余弦打分：

```python
class AAMSoftmax(nn.Module):
    """加性角间隔 Softmax：归一化特征与权重, 正确类角度加间隔 m。"""
    def __init__(self, d, n_spk, m=0.2, s=30.0):
        super().__init__()
        self.W = nn.Parameter(torch.randn(n_spk, d))
        self.m, self.s = m, s
    def forward(self, emb, labels):             # emb:[B,D], labels:[B]
        emb = F.normalize(emb, dim=1)           # 特征归一化到单位长
        W = F.normalize(self.W, dim=1)          # 权重归一化
        cos = emb @ W.t()                       # [B, n_spk]  = cosθ
        theta = torch.acos(cos.clamp(-1+1e-7, 1-1e-7))
        # 只给正确类加间隔 m
        target_logit = torch.cos(theta + self.m)        # cos(θ_y + m)
        onehot = F.one_hot(labels, cos.size(1)).float()
        logits = self.s * (onehot * target_logit + (1 - onehot) * cos)
        return F.cross_entropy(logits, labels)

N_SPK = 10
head = AAMSoftmax(D, N_SPK)
labels = torch.randint(0, N_SPK, (B,))
loss = head(emb, labels)
print("AAM loss:", loss.item())

# 推理打分：两段语音 → 两个指纹 → 余弦相似度
e1 = F.normalize(net(torch.randn(1, T, Fdim)), dim=1)
e2 = F.normalize(net(torch.randn(1, T, Fdim)), dim=1)
score = (e1 * e2).sum().item()                  # 余弦相似度 ∈ [-1,1]
print("cosine score:", round(score, 3))         # 超过阈值 τ 判同一人
```

训练头把特征和权重都归一化、在正确类角度上 `+m` 再算交叉熵——这段代码就是第四节那个公式的字面实现。推理时只用骨干出指纹、算余弦。全部真实 API：`F.normalize`、`F.one_hot`、`cross_entropy`，无发明函数。

## 七、这在工程里解决什么问题

| 场景 | 任务 | 阈值怎么定 |
|---|---|---|
| 手机/支付语音解锁 | 确认 1:1 | FAR 压到极低（别人解不开优先），牺牲点 FRR |
| 智能音箱认主人/个性化 | 确认 1:1 | 平衡，偏体验 |
| 会议记录分清谁在说 | 辨认/聚类 1:N | 结合时间信息做说话人日志（diarization） |
| 门禁/刑侦比对 | 确认/辨认 | 高安全，极低 FAR + 多轮核验 |

一线视角：
- **信道/环境失配是头号敌人**：注册用手机、验证用蓝牙耳机，指纹就偏。工程上靠大量跨信道数据训练、或指纹域适配来缓解。
- **短语音难**：只说两个字，统计池化的均值/方差估不准，指纹不稳。确认系统常要求最短注册/验证时长。
- **防录音回放攻击**：声纹本身防不了别人放你的录音——要配活体检测（反欺骗 anti-spoofing）才安全。这是面试高频追问。
- **抗噪**：嘈杂环境下指纹质量掉——所以常在声纹前面挂一级语音增强先洗干净，这正好引出下一篇。

## 八、埋一个钩子

声纹、唤醒、识别——到这里为止，我们默认喂进模型的语音都是**相对干净**的。可现实里麦克风收到的往往是人声裹着风扇声、键盘声、路噪。噪声一上来，指纹偏、识别错、唤醒漏。那在把语音交给这些模型之前，怎么先用一个网络**把噪声洗掉、只留人声**？下一篇进入**语音增强**（本篇自足，不依赖前面的 3A 系列也能读）。

## 本篇小结

- **声纹的本质**：不认内容、只认身份，把变长语音 `[B,T,F]` 压成固定维指纹 `[B,D]`，训练目标是"同人近、异人远"的几何结构，而非分类对错。确认(1:1)与辨认(1:N)底层同源。
- **第一件事·池化成定长**：平均池化丢信息；**统计池化**保留均值+标准差（声音的中心长相+抖动幅度）；**注意力统计池化**给每帧学权重，压低静音/噪声帧。时间维 T 在这一步被抹掉。
- **骨干(ECAPA-TDNN)**：TDNN/膨胀卷积打底 + SE-Res2 多尺度与通道强调 + 深浅层特征聚合，目的是在池化前把帧级特征做厚。
- **第二件事·间隔损失**：普通 Softmax 只分类、不保证"类内紧类间远"；**AAM-Softmax** 归一化后在正确类角度硬加间隔 $m$，逼同人聚拢、异人张开，正好配推理的余弦打分。
- **第三件事·打分与指标**：注册取指纹平均当模板，余弦相似度超阈判同人；**EER（FAR=FRR 点）**是与阈值无关的评测指标，部署阈值按安全偏好单独定（高安全压 FAR）。
- **工程意义**：信道失配、短语音、回放攻击、噪声是四大实战难题；噪声那条直接引出语音增强。
- **下一步**：在把语音交给识别/声纹之前，先用一个网络把噪声洗掉的语音增强。
