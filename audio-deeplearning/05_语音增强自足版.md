# 第 5 篇｜语音增强：不造声音，只给每个时频点学一个"保留多少"的旋钮

> 一句话核心直觉：语音增强（降噪）最聪明的做法不是让网络凭空"画"出干净语音，而是让它只做一件保守得多的事——看着带噪的时频谱，给**每一个时频点**学一个 0 到 1 之间的"保留多少"的旋钮（这叫掩码 mask），把旋钮乘回带噪谱，噪声大的点拧小、人声强的点保留。再往前一步，连相位一起修，就要估**复数掩码**。本篇从零讲透"掩码法增强"：为什么掩码比直接回归谱更稳、理想掩码长什么样、小 CRN 怎么估复数掩码、以及为什么用 SI-SNR 当损失。读完你能独立看懂一类主力降噪模型（本篇自足，不依赖之前的 3A 系列）。

---

## 一、先把教材那套扔一边

前四篇我们默认喂给模型的语音是干净的。可现实里，麦克风收到的是人声裹着风扇、键盘、路噪、人群嗡嗡声。噪声一上来，声纹指纹偏、识别出错、唤醒漏触发。所以在把语音交给那些模型之前，常要先过一级**语音增强**：输入带噪语音，输出尽量干净的语音。

传统降噪（谱减法、维纳滤波，信号处理那套）靠估计噪声谱再减掉，对**平稳噪声**（持续稳定的风扇声）还行，但对**非平稳噪声**（突然的关门声、键盘的敲击）就跟不上——它来不及更新噪声估计。深度学习降噪想解决的正是这个：**让网络从数据里学会，在任意时频点上判断"这里有多少是人声、多少是噪声"**，不管噪声平不平稳。

那网络具体输出什么？这里有一个非常关键、也最容易想歪的设计抉择，是本篇的起点。

---

## 二、核心抉择：直接回归干净谱，还是估一个掩码？

### 2.1 两条路

带噪语音做 STFT 得到带噪谱 $Y$（时间-频率的复数图，signals 系列讲过）。要得到干净谱 $\hat S$，有两种让网络干活的方式：

- **直接回归**（mapping）：让网络直接输出干净谱 $\hat S = f(Y)$。网络得凭空"画"出每个时频点的干净值。
- **估掩码**（masking）：让网络只输出一个掩码 $M = f(Y)$，再 $\hat S = M \odot Y$（逐点相乘）。网络只需判断"每个点保留多少比例"。

### 2.2 为什么掩码法更稳

想象一个时频点，带噪值是 3.0，其中人声贡献 2.4、噪声贡献 0.6。

- 直接回归要网络**输出 2.4** 这个绝对值——它得学会在各种音量、各种内容下都把绝对值估准，输出范围无界，难。
- 掩码法只要网络**输出 0.8** 这个比例（2.4/3.0），再乘回 3.0 得到 2.4。输出被限制在 0~1，而且"保留多少"比"绝对值多少"是个**好学得多的相对量**——它和整体音量无关，网络不用操心输入响不响。

> **关键认知**：掩码法把"画出干净语音"这个无界的生成难题，降格成"给每个时频点拧一个 0~1 的音量旋钮"的有界判别难题。这就是"逐频带增益=给每段单独拧音量旋钮"那个比喻的精确版——只不过现在是逐**时频点**拧，而且旋钮值由网络看着上下文学出来。掩码法训练更稳、泛化更好，是判别式降噪的主流。

### 2.3 理想掩码长什么样（IRM）

训练时的"标准答案"掩码从哪来？假设我们有配对的干净语音 $S$ 和噪声 $N$（降噪数据就是这么合成的：拿干净语音 + 噪声按不同信噪比混出带噪语音）。那"理想比值掩码"IRM 定义为：

$$ M_{\text{IRM}}(t,f) = \sqrt{\frac{|S(t,f)|^2}{|S(t,f)|^2 + |N(t,f)|^2}} $$

逐项翻译：分子是这个时频点人声的能量，分母是人声+噪声的总能量。比值就是"这个点里人声占的能量份额"，开根号是为了配功率谱。人声占主导的点 → 接近 1（保留）；噪声占主导的点 → 接近 0（压掉）。网络的训练目标，最朴素就是去回归这个 IRM。

但 IRM 有个致命局限：它只修**幅度**，不碰**相位**。

---

## 三、相位这道坎：从实数掩码到复数掩码

### 3.1 为什么相位不能不管

STFT 谱是复数，每个时频点有幅度和相位。IRM 这类实数掩码只缩放幅度，相位直接沿用**带噪的相位**。在信噪比高时还行，但信噪比一低，带噪相位本身就是错的——你把幅度修得再准，套上一个错的相位，重建出的波形还是毛。signals 系列反复强调过：相位携带波形的精细结构，低信噪比下相位误差直接变成听感上的"水声""金属声"。

### 3.2 复数比值掩码 CRM

于是升级到**复数比值掩码**（CRM）：掩码本身是复数 $M = M_r + jM_i$，直接作用在复数带噪谱上：

$$ \hat S = M \odot Y = (M_r + jM_i)(Y_r + jY_i) $$

复数相乘同时改变幅度**和**相位——于是网络一并把相位也修了。逐项翻译：$M_r, M_i$ 是网络输出的掩码实部和虚部两张图，和带噪谱的实虚部做复数乘法，输出的 $\hat S$ 幅度相位都被调整过。实践中网络就输出两个实数通道（实部图、虚部图），`[B, 2, F, T]`。

> **关键认知**：从 IRM 到 CRM，是从"只拧音量旋钮"升级到"同时拧音量和相位旋钮"。多出来的那个相位自由度，是低信噪比下听感能上一个台阶的关键。代价是网络要同时学好实虚两部分，训练更难、也更吃数据。

## 四、骨干：小 CRN —— 卷积编码解码 + GRU 瓶颈

估掩码的网络用什么结构？主流是 **CRN**（卷积循环网络），一个在频谱上做的编码器-解码器（U-Net 式）：

```
带噪谱 [B,2,F,T]
   │  编码器：几层 Conv2d，频率维逐步下采样（抽时频局部图案，F 变小、通道变多）
   ▼
瓶颈 [B,C,F',T]  ──► 沿时间的 GRU（跨帧传递上下文、建模噪声/语音的时间演变）
   │  解码器：几层 ConvTranspose2d，频率维逐步上采样（配跳连 skip，还原分辨率）
   ▼
掩码 [B,2,F,T]  ──► 和带噪谱复数相乘 ──► 估计干净谱 ──► iSTFT ──► 干净波形
```

逐块翻译为什么是这些零件：
- **卷积编码/解码**：时频谱上，人声的谐波、噪声的纹理都是**局部图案**，卷积最擅长抓局部、而且参数共享省算力。编码下采样是为了用更少的点概括更大的时频区域，解码上采样还原回原分辨率。
- **跳连**（skip connection）：把编码器对应层的细节直接接到解码器，防止下采样把精细信息丢光（U-Net 的标准招）。
- **GRU 瓶颈**：卷积只看局部窗口，但"这个噪声是不是持续的""人声是不是刚起"需要**跨帧的时间上下文**。在瓶颈处沿时间跑一个 GRU，把时间演变建模进来——而且 GRU 天然可以做**流式**（维护一个隐状态，来一帧更一帧），这是降噪能实时上线的命门。

> **关键认知**：CRN 不是什么新发明，就是把你已经熟的零件按任务拼起来——卷积管时频局部、GRU 管时间演变、U-Net 跳连管细节保留。任何一个复杂降噪模型拆开看，都是这几样的重新组合。

## 五、损失：为什么用 SI-SNR 而不是谱 MSE

掩码估出来、谱重建了，拿什么当损失训？

最直接是对掩码或谱做 MSE。但谱 MSE 有个老问题：它在谱域逐点算误差，和**人耳听到的波形质量**对不齐——谱上误差小不代表听着干净（相位、整体缩放它都不敏感）。

降噪领域更爱用 **SI-SNR**（尺度不变信噪比），直接在**时域波形**上算。它的思路：把估计波形 $\hat s$ 投影到目标波形 $s$ 的方向上，分解成"目标分量"和"残差"，算两者能量比：

$$ s_{\text{target}} = \frac{\langle \hat s, s\rangle}{\|s\|^2}\, s, \quad e = \hat s - s_{\text{target}}, \quad \text{SI-SNR} = 10\log_{10}\frac{\|s_{\text{target}}\|^2}{\|e\|^2} $$

逐项翻译：先把估计信号 $\hat s$ 往目标 $s$ 的方向投影，得到和目标同方向的那部分 $s_{\text{target}}$（$\langle\cdot,\cdot\rangle$ 是内积）；剩下的 $e$ 是偏离目标的残差；SI-SNR 就是"对的部分能量 / 错的部分能量"取对数。"尺度不变"是指它先投影、对整体音量放大缩小不敏感——网络只要把**波形形状**修对，不用操心输出响不响。训练时最大化 SI-SNR，等价于最小化 $-$SI-SNR。

> **关键认知**：SI-SNR 直接盯住"重建波形像不像目标"，而且对音量尺度免疫——这正好补上谱 MSE 和听感脱节的毛病。它是语音增强/分离的事实标准损失。注意它要在波形域算，所以网络估完谱得 iSTFT 回波形再算损失，相位修得好不好在这里直接体现。

## 六、代码实战：一个最小 CRN 估复数掩码 + SI-SNR 损失

CPU 可跑。搭一个极小 CRN，吃带噪复数谱的实虚两通道 `[B,2,F,T]`，出复数掩码，复数相乘得估计谱；再实现 SI-SNR 损失。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)
B, Fbin, Tframe = 2, 64, 50     # 批2, 64 频点, 50 帧

class TinyCRN(nn.Module):
    """最小 CRN：Conv2d 编码 → GRU 瓶颈 → ConvTranspose2d 解码，输出复数掩码(2通道)。"""
    def __init__(self, ch=16):
        super().__init__()
        # 编码器：频率维下采样（stride 在 F 轴 =2），通道 2->ch->ch*2
        self.enc1 = nn.Conv2d(2,  ch,   (3,3), stride=(2,1), padding=(1,1))
        self.enc2 = nn.Conv2d(ch, ch*2, (3,3), stride=(2,1), padding=(1,1))
        # 瓶颈 GRU：沿时间跑，输入特征维 = ch*2 * F''（把频率和通道摊平）
        self.rnn_feat = None     # 延迟到 forward 里按实际 F'' 建
        self.gru = None
        self.ch = ch
        # 解码器：频率维上采样回去，带跳连所以输入通道翻倍
        self.dec2 = nn.ConvTranspose2d(ch*2*2, ch, (3,3), stride=(2,1), padding=(1,1), output_padding=(1,0))
        self.dec1 = nn.ConvTranspose2d(ch*2,   2,  (3,3), stride=(2,1), padding=(1,1), output_padding=(1,0))

    def forward(self, x):                       # x: [B, 2, F, T]  (实部/虚部两通道)
        e1 = F.relu(self.enc1(x))               # -> [B, ch,   F/2, T]
        e2 = F.relu(self.enc2(e1))              # -> [B, 2ch,  F/4, T]
        Bs, C, Fp, Tp = e2.shape
        # 摊平 (C,Fp) 当特征, 沿时间 Tp 跑 GRU
        if self.gru is None:
            self.gru = nn.GRU(C * Fp, C * Fp, batch_first=True).to(x.device)
        g = e2.permute(0, 3, 1, 2).reshape(Bs, Tp, C * Fp)   # [B, T, C*Fp]
        g, _ = self.gru(g)                      # [B, T, C*Fp]  跨帧时间建模
        g = g.reshape(Bs, Tp, C, Fp).permute(0, 2, 3, 1)     # 回 [B, 2ch, F/4, T]
        d2 = F.relu(self.dec2(torch.cat([g, e2], dim=1)))    # 跳连 e2 -> [B, ch, F/2, T]
        mask = self.dec1(torch.cat([d2, e1], dim=1))         # 跳连 e1 -> [B, 2, F, T]  复数掩码
        return mask

def complex_mul(mask, y):
    """复数相乘：mask/y 都是 [B,2,F,T]（通道0=实, 1=虚）。"""
    mr, mi = mask[:,0], mask[:,1]
    yr, yi = y[:,0], y[:,1]
    sr = mr*yr - mi*yi        # 实部
    si = mr*yi + mi*yr        # 虚部
    return torch.stack([sr, si], dim=1)        # [B,2,F,T]  估计干净谱

crn = TinyCRN()
Y = torch.randn(B, 2, Fbin, Tframe)             # 带噪复数谱（实虚两通道）
mask = crn(Y)
S_hat = complex_mul(mask, Y)
print("Y     :", Y.shape)                       # torch.Size([2, 2, 64, 50])
print("mask  :", mask.shape)                    # torch.Size([2, 2, 64, 50])
print("S_hat :", S_hat.shape)                   # torch.Size([2, 2, 64, 50])
```

关键看数据流：带噪谱 `[2,2,64,50]` 经编码器把频率维 64→16（下采样两次），瓶颈处摊平成特征喂 GRU 做时间建模，解码器配跳连还原回 `[2,2,64,50]` 的复数掩码，再和带噪谱**复数相乘**得到估计干净谱——相位在这一步被一起修了。

```python
def si_snr_loss(est, ref, eps=1e-8):
    """SI-SNR 损失（在时域波形上算）。est/ref: [B, L]。返回 -SI-SNR 的均值。"""
    est = est - est.mean(dim=1, keepdim=True)   # 去均值
    ref = ref - ref.mean(dim=1, keepdim=True)
    # 把 est 投影到 ref 方向
    dot = (est * ref).sum(dim=1, keepdim=True)
    ref_energy = (ref * ref).sum(dim=1, keepdim=True) + eps
    s_target = dot / ref_energy * ref           # 目标分量
    e_noise = est - s_target                    # 残差
    ratio = (s_target**2).sum(dim=1) / ((e_noise**2).sum(dim=1) + eps)
    si_snr = 10 * torch.log10(ratio + eps)      # [B]
    return -si_snr.mean()                       # 最大化 SI-SNR = 最小化它的负

# 演示：假装 iSTFT 后得到波形（这里直接造一段）
est_wave = torch.randn(B, 8000)
ref_wave = torch.randn(B, 8000)
loss = si_snr_loss(est_wave, ref_wave)
print("SI-SNR loss:", round(loss.item(), 3))    # 随机波形下接近 0 dB 附近
```

真实训练里，`S_hat` 要先 `torch.istft` 回波形再喂 `si_snr_loss`（这里为演示直接造波形）。全部真实 API：`Conv2d`/`ConvTranspose2d(output_padding=)`、`GRU`、`torch.stack`、`log10`，复数乘法手写展开（也可用 `torch.complex`），无发明函数。

## 七、这在工程里解决什么问题

| 需求 | 做法 |
|---|---|
| 实时通话/会议降噪 | CRN 的 GRU 做流式（维护隐状态逐帧推理），卷积因果化（padding 砍右侧）不看未来帧 |
| 识别/声纹前置清洗 | 降噪当前端，先洗干净再喂给第 1/4 篇的模型（但要防"过度降噪"伤识别，见下） |
| 平稳 + 非平稳噪声都要治 | 掩码法从数据学，不依赖噪声平稳假设，天然比谱减法强 |
| 端侧算力 | 砍通道数/GRU 维度；复数运算定点化要留足 headroom（实虚两路都要） |

一线视角：
- **指标与听感背离**：PESQ/STOI 高不等于听着舒服，也不等于识别率高。有名的坑是**过度降噪**——把噪声压得很干净，却也把人声的弱辅音抹掉了，PESQ 好看、ASR 反而变差。所以降噪给识别用时，宁可留点残噪也别伤语音。
- **因果红线**：实时降噪不能看未来帧，卷积要因果化、GRU 本就单向——这条和前面几篇（KWS/ASR）是同一条红线。
- **数据合成是半壁江山**：降噪训练数据靠"干净语音 + 噪声按随机信噪比在线混"合成，噪声库的多样性（含非平稳、含混响）直接决定泛化。本系列用到的 VoiceBank+DEMAND 就是这类配对数据。
- **复数掩码的定点坑**：实虚两路相乘在定点下容易溢出/精度丢失，部署量化时要单独给 headroom，这比纯幅度掩码难调。

## 八、埋一个钩子

到这里，语音五大任务——识别、合成、唤醒、声纹、增强——的核心模型我们都拆过了。但这些模型现在还都躺在实验室：用高精度浮点、在大显存 GPU 上训出来的大家伙。真正要上手机、上耳机、上音箱，还隔着一整条工程链：怎么把它训好、怎么用少量数据微调到新场景、怎么把大模型蒸馏成小模型、怎么量化成 INT8、怎么导出部署还能流式实时跑？下一篇是收官的**训练·微调·蒸馏·量化·部署**工程篇。

---

## 本篇小结

- **核心抉择**：别让网络凭空"画"干净谱（无界回归，难），让它**估一个 0~1 掩码**再乘回带噪谱（有界判别，稳）。掩码=给每个时频点拧一个"保留多少"的音量旋钮。
- **理想掩码 IRM**：人声能量 / (人声+噪声) 能量，训练标答由配对的干净语音+噪声合成得到；局限是只修幅度、不碰相位。
- **复数掩码 CRM**：掩码是复数，复数相乘同时修幅度和相位，低信噪比下听感上台阶；网络输出实虚两通道 `[B,2,F,T]`。
- **骨干 CRN**：Conv2d 编码解码抓时频局部 + U-Net 跳连保细节 + GRU 瓶颈建模时间演变（且天然可流式），就是熟零件按任务重组。
- **损失 SI-SNR**：在时域波形上投影分解算"对/错能量比"，尺度不变、盯住重建波形像不像，补上谱 MSE 和听感脱节的毛病，是增强/分离的事实标准损失（需 iSTFT 回波形算）。
- **工程意义**：流式+因果上实时；给识别用要防过度降噪；数据靠在线混噪合成；复数掩码定点化要留 headroom。
- **下一步**：把这五类实验室模型，走完训练→微调→蒸馏→量化→部署的落地工程链。
