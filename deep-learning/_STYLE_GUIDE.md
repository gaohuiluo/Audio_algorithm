## 1. 五条硬约束（与 signals 系列完全一致）

### 1.1 直觉先行，数学兜底
每个概念**先给物理/工程画面，再上公式**。公式只保留最核心的那一个，出现时**必须逐项翻译成人话**。绝不先甩一堆推导。
> 例：讲反向传播先带读者"顺着一条责任链条往回问：是谁、错了多少"，等直觉建立了，链式法则 $\frac{\partial L}{\partial w}=\frac{\partial L}{\partial y}\frac{\partial y}{\partial w}$ 才变得顺眼。

### 1.2 所有例子锚定音频/语音
一律用声音、语音、音频处理举例。张量的每个维度都要落到真实含义（`[B, C, F, T]` = 批次/通道/频率/帧）。损失函数举例就用"降噪后和干净语音差多少"，绝不用"预测房价差多少"。

### 1.3 比喻必须有解释力，拒绝装饰性换名
只保留能**揭示机制**的比喻（梯度消失=悄悄话传了 100 个人已听不清、显存=工作台面积、mask=给频谱蒙一层透光度不同的膜）。坚决去掉只换花哨说法、不推进理解的修辞。直接描述事物本身。

### 1.4 代码把公式变成可视化/可运行
用 Python（PyTorch + NumPy + Matplotlib）把概念跑出来。代码要能直接跑、注释讲清每步在干嘛。张量操作后**务必打印/标注 shape**（这是本系列的教学重点之一）。
**配图**：每篇在关键原理点配 PNG 说明图（数据类图用真实代码/数据跑出来，示意类图用 matplotlib 方框箭头绘制）。图存 `assets/`，正文用 `![中文alt](assets/figNN_xxx.png)` + 一行斜体图注引用；生成脚本保留为 `assets/gen_fig_NN.py`（复用统一头部：YaHei 字体、配色常量、`save`/`_box`/`_arrow` 辅助函数），一条命令可重跑重现全部图。WAV 等音频产物仍不单独生成。

### 1.5 讲"为什么需要"，落到工程
重点是"工程中遇到什么问题、为什么要这个工具"，而非 API 罗列。凡有条件，补一段一线工程视角（显存 OOM 的真实场景、驱动层 ring buffer 与 batch 的对齐、实时推理的因果性约束、定点化对复数运算的影响等）。

## 5. 各篇内容要点清单（供执笔者展开，非逐字稿）

### 01 从 STFT 到 Tensor
- 从 signals 第 13 篇那张语谱图切入：`np.ndarray` → `torch.Tensor` 到底多了什么（device、dtype、autograd、batch 维）。
- 复数 Tensor：`torch.stft` 返回 complex64；`torch.view_as_real` 拆实虚；幅度 `.abs()`、相位 `.angle()`。强调**相位这次先留着，别急着扔**（给 07 埋伏笔）。
- shape 之旅：`[T]` 波形 →（stft）→ `[F, T]` 复数谱 →（加 batch/channel）→ `[B, C, F, T]`。每步打印 shape。
- 批次化为什么必要：GPU 要吃"整齐的方块"；变长音频→ padding + length mask 的坑（为 08 Mask Loss 埋点）。
- 代码：读一段（或合成）音频→`torch.stft`→看 shape/dtype→拆幅度相位→堆成 batch。

### 02 nn.Module 与数据管道
- nn.Module = "带可学习参数(旋钮)的函数"：`__init__` 里注册层，`forward` 里定义数据怎么流。parameters()/state_dict 直觉。
- 一个最小可运行例子：一个把 `[B,F,T]` 幅度谱映射到同尺寸 mask 的小网络。
- Dataset：`__len__`/`__getitem__`，一条样本 = 一段音频对（带噪 + 干净）。
- DataLoader：batch、shuffle、num_workers、collate_fn（变长 padding 就在这里，接 01 的坑）。
- 工程视角：驱动层 ring buffer 的流式数据 vs 训练时的随机批采样，思路差异。
- 代码：定义 Dataset + DataLoader + 一个 nn.Module，跑通一个 forward。

### 03 显存与混合精度
- 显存里到底装了什么：参数、梯度、优化器状态(Adam 的两倍)、激活值(反传要缓存，最吃显存)。
- OOM 的真实场景与算账：batch×序列长度×通道 怎么乘爆显存。
- 省显存工具箱：减 batch、梯度累积、`torch.no_grad()`/eval、梯度检查点(activation checkpointing)、`del`+`empty_cache` 的真相。
- 混合精度：fp16/bf16 vs fp32，为什么能省一半、为什么会数值下溢；`autocast` + `GradScaler` 怎么用、原理。
- 工程视角：训练/推理显存差异，实时推理为什么常用 fp16/int8。
- 代码：同一模型 fp32 vs autocast 的显存与速度对比（用 `torch.cuda.max_memory_allocated`，并给 CPU 回退说明）。

### 04 神经网络基础
- 全连接层就是 `y = Wx + b`：把它看成"一堆加权投票"。
- 反向传播直觉：责任链条往回问"谁错了多少"，链式法则逐项翻译；一次前向+反向+更新的完整循环。
- 为什么要激活函数：没有它，多少层线性叠起来还是一条直线（掰不弯）。
- 激活函数在音频里的选择：ReLU/LeakyReLU/PReLU（幅度谱恒非负的坑）、Sigmoid（做 mask 天然落在 [0,1]，接 08）、Tanh、GELU；掩码用 sigmoid 的理由。
- 代码：手写一个两层 MLP 对语谱图帧做非线性变换，`loss.backward()` 后打印某个权重的 `.grad`，看"责任"长什么样。

### 05 CNN 处理语谱图
- 语谱图 = 单通道图像（`[B,1,F,T]`）：把 signals 的语谱图和图像做类比，但强调两个轴含义不对称（频率 vs 时间）。
- 卷积核的物理含义：一个 3×3 核就是一个可学习的"局部时频模式探测器"（如检测某个谐波斜率、某个共振峰团、瞬态竖条）。呼应 signals 里读语谱图那节。
- 感受野 = 看多大一片上下文：层叠/stride/dilation 如何扩大感受野；为什么降噪需要足够上下文。
- 频率轴与时间轴该不该同等对待：2D 卷积 vs 沿频率的卷积；因果卷积（实时推理不能看未来帧，接 06/工程）。
- 代码：一个小 CNN 对语谱图卷积，可视化/打印卷积核和 feature map 的 shape 变化，算一算感受野。

### 06 RNN / LSTM / GRU 与时间序列
- 为什么要 RNN：语音是时间序列，当前帧依赖历史；RNN 把隐状态沿时间传递（记忆）。
- 梯度消失/爆炸：直觉——梯度沿时间连乘，<1 越乘越小(悄悄话传 100 人)、>1 越乘越炸。这是 04 反传直觉的时间展开版。
- LSTM/GRU：门控如何"选择性记忆/遗忘"，为长依赖开一条梯度高速路(cell state)。逐门翻译成人话。
- 双向 RNN 的工程限制：bidirectional 要看完整段才能出结果 → 实时/低延迟场景不可用（因果性）；离线降噪可用。呼应 05 因果卷积。
- 代码：一个 LSTM 对 `[B,T,F]` 序列建模，打印隐状态/输出 shape；小实验展示长序列上梯度范数的衰减。

### 07 复数神经网络基础
- 承接 01/06：前面都在啃幅度谱、把相位扔了。为什么相位不能扔（signals 第 8 篇：相位携带波形结构/对齐信息，降噪/分离恢复相位很关键）。
- 复数线性层 ComplexLinear：复权重 $W=A+iB$ 作用于复输入 $z=x+iy$，`(A+iB)(x+iy)` 展开成实部虚部两套实数矩阵乘。逐项翻译，配 shape。
- 为什么"语音离不开复数网络"：复数谱直接建模、相位一致性、DCCRN/复数 mask 等实际用途（点到即止，不堆论文）。
- 复数激活、复数 BN 的思路简述（不深挖）。
- 工程视角：定点化/推理框架对复数支持差 → 常拆成实虚双通道实数网络的折中。
- 代码：手写 ComplexLinear（用两套实数 Linear 拼），对复数谱做一次变换，验证与 `torch.complex` 手算一致。

### 08 损失函数
- MSE 为何不够用：逐点平方差 = 只看数值贴合，不对齐感知；幅度谱 MSE 对能量大处偏心、忽略相位、对整体缩放敏感。
- Mask Loss：预测 mask×带噪谱 ≈ 干净谱，损失定义在重建谱上；理想比值掩码(IRM)/理想二值掩码(IBM)直觉。承接 01 的 length mask（padding 处不计损失）。
- SI-SNR（尺度不变信噪比）：为什么语音分离/降噪用它——对增益不敏感、直接对齐"目标语音能量 vs 残差能量"。公式逐项翻译（投影出目标分量、算能量比、取 log）。
- 组合损失、时域 vs 频域损失取舍。
- 代码：实现 MSE、Mask Loss、SI-SNR，同一对(估计,目标)信号上对比三者数值与梯度行为。

### 09 优化器 AdamW
- 承接 08：有了损失这座山，怎么下山。
- SGD：最朴素的顺坡走；学习率太大震荡、太小龟速。
- Momentum：给下山加惯性，冲过小坑与鞍点。
- RMSProp/Adam：每个参数自适应步长（一阶矩+二阶矩），逐项翻译 Adam 更新式；为什么 Adam 是深度学习默认。
- AdamW：Adam 里 L2 正则和权重衰减被耦合错了，AdamW 把 weight decay 解耦——工程上这点差异对泛化的真实影响。
- 学习率调度(warmup/cosine)一句带过。
- 工程视角：优化器状态吃显存（接 03）、混合精度下的 GradScaler（接 03）。
- 代码：在一个小问题上对比 SGD / Momentum / Adam / AdamW 的收敛曲线（画 loss 下降）。
- 收束全系列：从 STFT 张量到能训练的完整闭环已打通，下一段旅程是具体的降噪/分离模型实战。
